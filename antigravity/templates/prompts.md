# 따라 하기 요청문 모음

Antigravity 앱(또는 IDE)에서 `starter` 폴더를 열고 그대로 붙여 넣어 쓰는 요청문입니다.

## 1. 첫 작업 — 스네이크 게임 (계획 → 구현 → 브라우저 검증)

```
snake.html 한 파일(CSS·JavaScript 포함)로 레트로 초록 화면 스타일의 스네이크 게임을 만들어 줘.

[규칙]
1. 방향키로 뱀을 움직이고, 빨간 사과를 먹으면 몸이 한 칸 길어지며 10점을 얻는다.
2. 벽이나 자기 몸에 닿으면 게임 오버. 스페이스바로 다시 시작한다.
3. 시작 화면, 현재 점수, 최고 점수(브라우저에 저장)를 보여 준다.
4. 휴대폰에서도 할 수 있게 화면 아래에 방향 버튼을 둔다.

[진행 방식]
- 먼저 구현 계획(implementation plan)을 보여 주고 내 승인을 받은 뒤 만든다.
- 다 만들면 브라우저로 직접 열어 3분 정도 플레이해 보고, 스크린샷과 확인한 항목을 walkthrough에 정리한다.
```

계획 단계에서 고칠 점이 있으면 계획 문서에 바로 댓글을 달아 돌려보냅니다. 완성 후에는 이렇게 이어서 요청합니다.

```
게임 오버 뒤 스페이스바를 누르면 뱀이 이전 위치에서 다시 시작해. 처음 상태로 완전히 초기화되게 고치고, 고친 뒤 브라우저에서 다시 확인해 줘.
```
