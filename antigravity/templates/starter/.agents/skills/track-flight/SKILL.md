# 항공편 운항 상태 정리

## 입력
사용자가 `/track-flight` 뒤에 적은 항공편 번호(예: `KE017`, `OZ201`). 번호가 없으면 먼저 묻습니다.

## 절차
1. 브라우저로 항공사 공식 사이트나 공항 운항 정보 페이지를 먼저 찾습니다. 없으면 항공편 추적 사이트를 씁니다.
2. 출발지·도착지, 예정/실제(또는 예상) 출발·도착 시각, 현재 상태를 뽑습니다.
3. 시각에는 공항 현지 시간대를 붙입니다(예: 14:05 KST).
4. 두 출처의 값이 다르면 둘 다 적습니다.

## 출력
| 항목 | 내용 |
|---|---|
| 항공편 | (번호) |
| 노선 | 출발지 → 도착지 |
| 상태 | 정시 / 지연(분) / 결항 |
| 출발 | 예정 HH:MM · 실제 HH:MM (시간대) |
| 도착 | 예정 HH:MM · 예상 HH:MM (시간대) |

출처: (URL) · 확인 시각: (현지 시간)

> 실시간 정보는 몇 분 단위로 바뀝니다. 공항에 가기 전에는 항공사 앱으로 다시 확인하세요.
