# 사업 아이디어 평가

## 입력
`/evaluate-startup` 뒤에 적은 아이디어 한두 문장. 대상 고객이나 지역이 빠져 있으면 가정을 밝히고 진행합니다.

## 절차
1. **분해** — 대상 고객, 해결하려는 문제, 핵심 가치 제안으로 나눕니다.
2. **조사** — 브라우저로 시장 규모 추정 자료, 주요 경쟁 서비스 3곳 이상, 최근 1년 동향을 찾습니다. 숫자마다 출처를 붙입니다.
3. **평가** — 아래 세 항목을 1~10점으로 매기고, 점수마다 근거 문장과 출처를 답니다.
   - 시장성 · 경쟁 우위 · 실행 난이도(높을수록 쉬움)
4. **반대 의견** — 이 아이디어가 실패할 가장 그럴듯한 이유 3가지를 따로 적습니다.
5. **종합** — `추진 검토 / 보완 후 재검토 / 보류` 중 하나와 이유, 보완 전략 3가지.

## 출력
1. 분해 표 2. 점수 표(항목·점수·근거·출처) 3. 실패 시나리오 3가지 4. 종합 판단과 보완 전략

> 이 평가는 공개 자료로 만든 참고 의견입니다. 투자 권유가 아니며, 실제 결정 전에는 고객 인터뷰와 전문가 검토가 필요합니다.
