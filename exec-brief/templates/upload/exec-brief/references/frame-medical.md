# 의학·생명과학 (IMRaD · PICO)

## 뽑을 것 [원문]
- P 대상(질환·중증도·나이·인원) / I 개입 / C 비교(위약·표준치료) / O 결과(1차·2차 평가변수)
- 설계: 무작위배정 비교임상시험·코호트·환자-대조군·메타분석, 맹검, 추적 기간, 사전 등록 번호
- 효과: 효과 크기(위험비 HR·오즈비 OR·상대위험 RR·평균차)와 **95% 신뢰구간**, 가능하면 절대위험감소·치료필요수
- 안전성: 이상사례 비율, 중단율
- 재현: 데이터·프로토콜 공개, 자금 출처·이해관계

## 먼저 의심할 것
- p<0.05를 '효과가 크다'로 읽지 않기 — 효과 크기와 신뢰구간을 함께
- 대리 평가변수(혈중 수치 등)를 실제 임상 결과(사망·입원)처럼 쓰는가
- 상대위험만 있고 절대위험은 없는가(“위험 50% 감소”가 2%→1%일 수 있음)
- 하위군 분석 결과를 주 결론처럼 쓰는가
- 치료의향분석(ITT)인가, 프로토콜 순응 분석만인가

## 경영 관점 [해석]
표준치료 대비 위치, 임상 지침 반영 가능성, 규제·보험 급여까지 남은 단계
