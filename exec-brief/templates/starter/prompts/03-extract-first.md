# 추출 먼저, 요약은 나중에 (두 번에 나눠 묻기)

긴 문서나 중요한 문서는 한 번에 요약시키지 말고 두 단계로 나눕니다.

**1차 — 추출만**
```
첨부 문서에서 요약하지 말고 사실만 뽑아 줘.
| # | 주장 | 원문 구절(그대로) | 위치(쪽·절·표) | 수치·단위·비교 기준 |
저자가 밝힌 한계, 표와 본문의 수치 불일치도 행으로 넣어. 해석은 하지 마.
```

**2차 — 이 표만으로 작성**
```
위 사실표에 있는 내용만 써서 1쪽 브리핑을 작성해 줘(01 서식). 표에 없는 내용이 필요하면 '원문 확인 필요'로 표시해.
```

긴 문서(수십 쪽 이상)는 1차를 **장·절마다** 따로 하고 표를 합칩니다. 긴 문맥에서는 처음과 끝보다 가운데 정보를 놓치기 쉽습니다.
