# AI·컴퓨터 (성능 중심)

## 뽑을 것 [원문]
- 문제 정의와 기존 방법의 한계(저자 주장)
- 제안 방법의 핵심(구조·학습 방법·데이터)
- 벤치마크·평가 지표와 **비교 대상(베이스라인)**, 개선 폭(절대값과 상대값 모두)
- 연산 자원(GPU 종류·시간·매개변수 수), 추론 비용·지연 시간
- 코드·가중치·데이터 공개 여부와 라이선스

## 먼저 의심할 것
- 비교 대상이 최신이고 같은 조건(데이터·연산·튜닝 횟수)인가
- 벤치마크 문제가 학습 데이터에 섞였을 가능성(벤치마크 오염)
- 저자가 만든 자체 벤치마크만 쓰는가
- 평균만 있고 분산·반복 실험 횟수가 없는가
- 심사 전 사전 인쇄본(arXiv)인가

## 경영 관점 [해석]
도입 비용(학습·추론), 우리 데이터에서의 재현 가능성, 라이선스, 대체 기술과의 비교
