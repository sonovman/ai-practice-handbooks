# 연구·정책·컨설팅·기술 보고서

## 뽑을 것 [원문]
- 발행처·발행일·의뢰자(누가 돈을 냈나)·작성 방법(조사·모형·전문가 면담)
- 핵심 주장과 그 근거 자료(출처를 보고서가 밝힌 대로)
- 전망 수치는 **가정과 함께**(기준 연도, 시나리오, 성장률 가정)
- 권고 사항(보고서 주장)

## 먼저 의심할 것
- 시장 규모·전망 수치의 출처와 가정이 공개되어 있는가
- 의뢰자의 이해관계(판매·로비 목적)
- 발행일이 오래되어 상황이 바뀌었을 가능성 — '확인 필요'
- 2차 인용(다른 보고서 숫자를 다시 인용)인가

## 경영 관점 [해석]
우리 결정에 쓰려면 어떤 수치를 독립적으로 다시 확인해야 하는가
