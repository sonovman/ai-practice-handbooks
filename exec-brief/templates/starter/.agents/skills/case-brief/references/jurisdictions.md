# 관할별 판례 구조와 요약 포인트

| 관할 | 판결의 효력 | 요약에서 구분할 것 | 확인할 곳 |
|---|---|---|---|
| 한국 | 상급심 판단은 해당 사건의 하급심을 기속(법원조직법 제8조). 대법원 판례는 다른 사건에 법적 구속력은 없으나 사실상 강한 영향. 판례 변경은 전원합의체 | 공보의 판시사항·판결요지(법원 작성)와 본문 판단 / 다수의견·별개의견·보충의견·반대의견 / 파기환송·상고기각 | 대법원 누리집 판례 검색, 국가법령정보센터(law.go.kr), 법제처 Open API(8편) |
| 미국 | 선례구속(stare decisis). 같은 관할 상급 법원 판결이 구속. 비선례(non-precedential) 판결은 구속력 약함. 특허는 연방순회항소법원(CAFC) | holding(결론에 필요한 판단) vs dicta / majority·concurring·dissenting / 절차 단계(약식판결·배심 평결 후 등) | CourtListener, 법원 공식 사이트, Westlaw·Lexis |
| 영국 | 선례구속. ratio decidendi가 구속, obiter dicta는 참고. 중립 인용([2025] UKSC 1 등) | ratio vs obiter / 다수·소수 의견 / 하급심 결론과의 차이 | Find Case Law(국립기록원), BAILII |
| EU (CJEU) | 선결적 판단(preliminary ruling)은 회원국 법원에 구속력. 법무관(AG) 의견은 구속력 없음 | 회부된 질문(questions referred)과 주문(operative part)·판단 이유 / AG 의견과 법원 판단 구분 | CURIA, EUR-Lex(ECLI) |
| 일본 | 한국과 비슷한 대륙법계. 최고재판소 판례의 사실상 구속력, 판례 변경은 대법정 | 判示事項·判決要旨와 본문 / 補足意見·反対意見 | 裁判所 裁判例検索 |

## 요약에서 자주 무너지는 지점
- 다른 관할의 판결을 우리 사건의 '판례'처럼 옮기기 — 관할·법 조문·사실관계 차이를 먼저
- 하급심 판결을 확정 판결처럼 쓰기 — 상소 여부·확정 여부는 확인 필요
- 판결요지(요약)만 보고 본문 판단의 조건을 놓치기
- 번역: holding을 '보유', prosecution history를 '기소 이력'으로 옮기는 오역 → 용어집(glossary/patent-legal.csv)
