# 프로젝트 규칙 (항상 적용)

이 폴더는 논문·보고서·판례를 경영진과 전문가의 의사결정용으로 요약하는 작업 공간입니다.

- 답변과 산출물은 한국어로 씁니다. 원문의 고유명사·사건번호·수치·단위는 원문 표기 그대로 둡니다.
- 요약은 **추출 → 점검 → 작성 → 검증** 순서로 합니다. 원문을 다 읽기 전에 결론부터 쓰지 않습니다.
- 사실은 [원문] 구획에 원문 구절을 “큰따옴표”로 붙여 쓰고, 해석·권고는 [해석] 구획에 기대는 가정과 함께 씁니다.
- 원문에 없는 수치·판례·인용을 만들지 않습니다. 모르면 '원문에 없음' 또는 '확인 필요'.
- 원문에 없는 판례를 기억으로 인용하지 않습니다. 사용자가 요청하면 '공식 DB에서 확인할 후보'로만 표시합니다.
- 작업이 끝나면 `tools/evidence_check.py`, `tools/term_check.py`(용어집), 판례면 `tools/cite_check.py`를 돌려 판정을 함께 보고합니다.
- 원본 파일은 고치지 않고, 결과는 `work/` 아래에 저장합니다.
- 법률·의료·투자 판단은 전문가 확인이 필요하다고 표시합니다. 기밀 문서는 사용자가 허락한 환경에서만 다룹니다.
