# 특허로 읽는 시장 흐름 — 쓸 수 있는 것과 없는 것

특허 데이터는 '시장'을 직접 보여 주지 않는다. 기업이 **어디서 무엇을 지키려 하는지**를 보여 줄 뿐이다. 그래서 시장 신호는 항상 '신호'로 쓰고, 점유율·매출 판단은 외부 시장자료와 함께 한다.

| 특허에서 보이는 것 | 읽을 수 있는 시장 신호 | 함정 |
|---|---|---|
| 같은 기술의 출원 국가 수(패밀리 국가) | 그 기술을 여러 시장에서 팔 계획 | 비용 여유가 있는 대기업이 원래 넓게 낸다 — 그룹별 평소 습관과 비교 |
| 국가 구성의 변화(예: 미국·유럽 추가) | 새 시장 진출 준비 | 공개 지연 때문에 최근 진출은 늦게 보인다 |
| 새 출원인 그룹의 첫 출원(신규 진입) | 새 경쟁자, 인접 업종의 진입 | 대학·연구소는 제품 출시와 거리가 멀 수 있다 |
| 한 그룹의 연속·후속출원(T2) | 제품 세대 교체·집중 투자 | 분할·계속출원은 같은 기술의 재출원일 수 있다 |
| 기술군 비중의 이동(예: 기계 → 센서·앱) | 제품 가치의 중심 이동 | 검색식이 바뀌었는지 먼저 확인 |
| 중국 실용신안의 급증 | 빠른 제품화·저가 시장 경쟁 | 실용신안은 심사가 약해 권리 강도와 다르다 |
| 대학·연구소 출원 | 장기 대체기술, 라이선스 기회 | 상용화 일정은 따로 확인 |

## 보고서에 쓰는 방법
- "가나그룹만 같은 기술을 3개국에 출원했다"(관측) → "해외 판매를 염두에 둔 권리 확보로 보인다"(추론, 근거강도 표시) → "해외 매출 비중은 외부 자료로 확인 필요"(미확인).
- 숫자는 `02_stats`의 `family_coverage`, `multi_country_signals_by_group`, `country_targets`, 그룹별 `new_entrant`만 쓴다.
- 시장 규모·점유율·가격대가 결론에 필요하면, 사용자가 준 시장자료나 공신력 있는 공개자료(출처·날짜 명기)를 따로 붙인다. 없으면 '시장자료 미제공'으로 한계에 적는다.
