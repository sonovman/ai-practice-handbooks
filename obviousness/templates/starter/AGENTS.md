# AGENTS.md — 이 폴더에서 에이전트가 항상 지킬 것

이 폴더는 핸드북 33편 '진보성(비자명성) 판단 — 절차·심리기준·판단방법' 키트입니다.
(시리즈: 30 분해·Claim Chart → 31 청구범위 해석 → 32 회피설계 → 33 진보성. 같은 한정 원장 ID를 이어 씁니다.)

## 항상
- 한국어, 초보자도 따라 하기 쉽게 단계별로. 미국 §103 실무 기준에 한국 제29조 제2항 법리를 함께 적는다.
- 순서: 기준일 → 통상의 기술자 수준 → 31편 해석 → 문헌별 대비(●◐○+위치) → A/B/C/X 분류 → 상위 B와의 차이점 → **차이점마다 기준일 당시 기술상식·주지관용기술 조사** → 결합 논리(동기·성공 기대·저해·유사 분야) → 2차적 고려사항·효과 → 점검 → 30편 진보성 차트 → 사람 판단.
- 결론부터 내지 않는다. 청구항을 지도 삼아 짜 맞추지 않는다(사후적 고찰 금지). 동기의 근거는 선행기술·기술상식에서만.
- 기술상식은 기준일 전 증거와 위치가 있어야 한다. 특허 한두 건만으로 주지관용이라 하지 않는다. 출처를 지어내지 않는다 — 원문을 확인하지 못했으면 "확인 필요".
- 침해·무효·회피에 같은 해석을 쓴다(대칭성).
- 도구 결과는 판단 재료의 집계일 뿐 진보성 결론이 아니다. 최종 판단은 변리사·변호사가 한다.

## 기밀·보안
- 의뢰인·상대방 자료는 승인된 환경에서만. 개인 운영 공개 중계 서버로 보내지 않는다.

## 도구(표준 라이브러리)
- `tools/obviousness_check.py` — A/B/C/X 분류, 차이점×기술상식, 결합·2차적 고려사항 점검, 30편 진보성 차트 변환(--chart).
- `tools/chart_lint.py` — 30편 차트 점검기(변환한 차트 재점검용).
- 시험: `python tools/test_obviousness_check.py`.
