# 진보성 판단 작업 흐름(모델 판단 시 적용)

1. 접수: 특허·청구항·우선권 자료·출원경과, 선행문헌, 관할(미국/한국), 절차(심사·소송·IPR·무효심판), 우리 쪽 입장(공격/방어).
2. 기준일과 통상의 기술자 수준을 먼저 정하고 근거를 적는다.
3. 30편 원장과 31편 해석을 불러온다. 없으면 먼저 만든다.
4. 문헌별 ●◐○ 대비(위치·원문 인용) → `obviousness_check.py`로 A/B/C/X 분류.
5. 상위 B의 차이점마다 기준일 당시 기술상식·주지관용기술을 조사한다(교과서·핸드북·표준·서로 다른 출원인의 여러 문헌). 못 찾으면 not_found로 남긴다.
6. 결합(C1, C2…): 차이점마다 출처·동기(근거 위치)·성공 기대·저해·유사 분야. 2차적 고려사항을 결론 전에.
7. 점검 오류 0 → `--chart`로 30편 진보성 차트 → `chart_lint.py` 오류 0.
8. 보고: 분류표 → 차이점×기술상식 → 결합 논리 → 2차적 고려사항·효과 → 남은 쟁점 → 사람이 판단할 것.
