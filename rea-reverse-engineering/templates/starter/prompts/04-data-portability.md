# 내 데이터 꺼내기 (파일 포맷 분석 — 전형적 적법 사용)

문서가 사라진 독자 파일 포맷에 '내 데이터'가 갇혀 있을 때, 그 데이터를 꺼내는 파서를 만드는 예.

```
REA를 사용해서 [내 데이터가 든 .xxx 파일]의 바이너리 구조를 분석해 줘.
- 파일 헤더(매직 넘버), 레코드 경계, 문자열 인코딩, 길이 필드 위치를 근거(오프셋)와 함께 정리해 줘.
- 보호조치(암호화)가 걸려 있으면 우회하지 말고 거기서 멈추고 알려 줘.
- 파악한 구조로 '내 데이터'를 읽어 CSV/JSON으로 내보내는 파이썬 파서를 만들고, 몇 개 레코드로 검증해 줘.

이 파일들은 내가 만든/정당하게 보유한 데이터야. 목적은 다른 시스템으로의 이전(상호운용)이야.
```
