# 근거 규율 (REA Evidence v2 개념)

REA는 수집한 사실을 '근거' 객체로 묶어 돌려주고, 통과/실패/미확인을 구분합니다. 재구현 전에 이 규율을 지킵니다.

- 모든 '이렇게 동작한다'에는 **위치**가 있어야 함: 함수 주소(0x...), 소스 라인(file:line:col), .rodata 오프셋, HAR 엔트리 번호 등.
- 근거 종류를 구분: 의사코드 / 어셈블리 / 상수 / 호출관계(xref) / 문자열 / 네트워크.
- 확인 못 한 것은 **미확인(unknown)** 으로 명시. 특히 런타임에 동적으로 만들어지는 값(채널명·키)은 정적 분석으로 틀리기 쉬움.
- 상수는 바이트 그대로 적고 해석을 따로: 예) `9a9999999999693f` → double `0.003125`.
- 재구현 후 **원본과 대조**해서 통과로 바꿈. 실패가 남으면 보고에 그대로 드러냄.
