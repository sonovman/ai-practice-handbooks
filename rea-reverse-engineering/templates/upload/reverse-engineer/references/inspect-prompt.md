# 조사 요청 (근거 중심, 한 기능 단위)

> 먼저 `python tools/scope_check.py` 로 적법 범위를 확인하세요(GREEN일 때만).

```
REA를 사용해서 [대상 파일/폴더 경로]의 [하나의 기능, 예: '검색 로직' / '% 연산' / '파일 헤더 파싱']이
어떻게 동작하는지 조사해 줘.

- 근거(Evidence)와 위치를 함께 보여 줘: 함수 주소, 디컴파일 의사코드, 어셈블리, 메모리 상수, 또는 소스 라인(file:line:col).
- 확인되지 않은 부분은 '미확인(unknown)'으로 분명히 표시하고, 추측을 사실처럼 쓰지 마.
- 런타임에 동적으로 만들어지는 값(IPC 채널명, 키 등)은 정적 분석으로 틀릴 수 있으니 그렇게 표시해 줘.
- 원격 서버 로직, 보호조치 뒤의 내용은 분석하지 마.

대상은 [내가 만든 / 오픈소스(라이선스 확인함) / 분석 권한이 있는] 프로그램이야.
```
