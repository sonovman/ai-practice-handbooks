# AGENTS.md — 이 폴더에서 에이전트가 항상 지킬 것

이 폴더는 핸드북 24편 'AI 슬라이드 제작 워크플로우' 키트입니다.

## 항상
- 한국어로, 초보자도 따라 하기 쉽게 단계별로.
- 품질(객관)과 취향(스타일)을 분리한다. 품질은 Pass/Fail, 취향은 가이드로만.
- 1차 결과를 그대로 쓰지 않는다. 품질 게이트 + 비주얼 QA 루프 후 사람이 리터치한다.

## 워크플로우
1. 취향 추출: 우수 레퍼런스 → `디자인.md`(루브릭).
2. 생성: `본문.md` + `디자인.md` → 슬라이드 개요(Type 섞기). 긴 글은 챕터 병렬.
3. 검수(루프): `slide_lint.py`(객관) + `deck_html.py` 미리보기로 비주얼 QA.
4. 리터치: 사람 수정분을 `디자인.md`에 반영해 고도화.

## 하지 말 것
- 'A가 아니라 B' 등 AI 클리셰, 단조로운 표 반복.
- 레퍼런스·본문의 저작권/개인정보를 무시하고 올리기. 개인 운영 외부 서버 경유 금지.

## 도구(표준 라이브러리)
- `tools/slide_lint.py` — 품질 게이트 + 취향 점검(Pass/Fail).
- `tools/deck_html.py` — 슬라이드 개요 → 검토용 미리보기 HTML(비주얼 QA용, PPTX 아님).
- 시험: `python tools/test_slide_lint.py`, `python tools/test_deck_html.py`.
