# 🎨 디자인 취향 명세서 (디자인.md)

## 1. 디자인 시스템 & 컬러 규격
- 메인 컬러: 딥 네이비 (#1A2B4C) — 제목·강조 카드 테두리
- 포인트 컬러: 오렌지 (#FF6B35) — 수치·핵심 강조 키워드
- 배경: 오프화이트 (#F8F9FA), 무분별한 그라데이션 금지

## 2. 폰트 및 여백 비율
- 메인 타이틀: Bold 28pt / 좌측 상단 / 1줄
- 서브 헤드라인: Medium 18pt / 맥락 요약 1문장
- 본문: Regular 14pt / 행간 1.5 / 좌측 정렬

## 3. 레이아웃 다양성 패턴 (6종)
- Type A (비교 2분할): 좌우 대비 카드
- Type B (프로세스 4단계): 화살표 횡형 흐름
- Type C (3대 핵심): 상단 수치 + 하단 설명 박스
- Type D (핵심 1문장): 중앙 대형 메시지 + 하단 보조 칩
- Type E (매트릭스 2x2): 4분면 구분
- Type F (현황과 과제): 좌측 문제 / 우측 해결책

## 4. 논리 및 강약 전개
- AI 클리셰 금지: 'A가 아니라 B' 완전 배제
- 줄글 배제: 핵심 명사형 끝맺음 또는 수치 우선 노출
