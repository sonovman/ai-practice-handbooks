# 슬라이드 품질 게이트 점검

- 슬라이드 수: 5장
- 판정: **미통과**

## 품질 게이트 (Pass/Fail)

| 판정 | 항목 | 내용 |
|---|---|---|
| PASS | 분량(슬라이드 수) | 요구 5장 / 실제 5장 |
| PASS | 요구사항(키워드 포함) | 모두 포함 |
| FAIL | 사실관계(본문에 없는 수치) | 본문에 없음: 2027 |
| PASS | 문체(AI 클리셰 없음) | 없음 |

## 취향 경고 (참고)

- 특이사항 없음
