# 슬라이드 제작 작업 흐름(모델 판단 시 적용)

사용자가 "PPT/슬라이드를 AI로 잘 만들고 싶다 / 레퍼런스 스타일을 재현하고 싶다 / AI 티가 난다 / 검수를 자동화하고 싶다"고 하면 아래로 돕는다.

1. 취향 명세서(디자인.md)부터 — 우수 레퍼런스에서 컬러·폰트·레이아웃 다양성·강약·밀도를 루브릭으로 추출.
2. 본문 + 디자인.md로 개요 생성 — Type를 섞고, 클리셰·단조 표 반복 금지.
3. 품질 게이트(slide_lint.py, 객관 Pass/Fail) + 비주얼 QA(deck_html.py 미리보기, 눈으로).
4. 사람 리터치 → 디자인.md 고도화.
5. 실제 PPTX는 Slides 기능으로, 게이트를 통과한 개요만.

주의: 품질과 취향을 섞지 말 것. 모델 버전명은 자주 바뀌니 개념으로. 레퍼런스 저작권·개인정보 확인.
