# 클레임 차트 · FTO 분석

특허 판단의 단위를 "문서 대 문서"가 아니라 **"청구항 대 발명의 설명"**으로 잡습니다. 청구항은 그 특허의 발명의 설명으로 해석하고(같은 문헌 쌍), 해석된 구성요소가 대상 문서의 설명에 있는지(다른 문헌 쌍) 하나씩 확인합니다.

## 1. 목적에 따라 짝을 정한다

| 목적 | 청구항 (제1 텍스트) | 설명 (제2 텍스트) | 모든 구성요소가 개시되면 |
|---|---|---|---|
| FTO · 침해 위험 | 상대(권리자) 특허의 청구항 | 내 제품·서비스 기술 설명서 | 침해 위험 높음 |
| 신규성 · 선행기술 조사 | 내 발명(출원 예정)의 청구항 | 선행 문헌의 발명의 설명 | 신규성 부정 가능성 |
| 무효 자료 검토 | 상대 특허의 청구항 | 출원 전 선행 문헌 | 무효 근거 후보 |
| 유사 특허 판별 | 관심 특허의 청구항 | 비교 특허의 발명의 설명 | 실질적으로 같은 발명 |

목적이 분명하지 않으면 한 번 묻습니다. 청구항은 **독립항부터** 분석하고, 등록 전 출원이면 "청구항이 바뀔 수 있음"을 적습니다.

## 2. 진행 순서

1. **분설** — 청구항을 전제부와 구성요소 E1…En으로 나눕니다. `scripts/pairkit.py elements`의 초안을 출발점으로, 기능이 둘 섞인 구성요소는 나누고 잘린 의미 단위는 합칩니다. 청구항 문언은 바꾸지 않습니다.
2. **용어 해석 (같은 문헌 쌍)** — 구성요소의 핵심 용어마다 관심 특허 **자신의** 발명의 설명에서 정의·실시예 문단을 찾아 식별번호와 함께 적습니다. 다른 문헌의 뜻으로 해석하지 않습니다.
3. **근거 후보 (다른 문헌 쌍)** — 대상 문서가 짧으면 전문을, 길면 `pairkit.py bundle`이 고른 구성요소별 상위 조각을 봅니다. 글자 유사도는 후보를 좁히는 데만 쓰고 판단 근거로 쓰지 않습니다(같은 뜻을 다른 말로 쓴 문서는 점수가 낮게 나옵니다).
4. **구성요소별 판단** — `개시` / `부분 개시` / `불명` / `미개시` 중 하나. 개시·부분 개시는 대상 문서 문장을 **그대로 인용**하고 식별번호를 붙입니다. 근거를 찾지 못하면 지어내지 말고 불명·미개시로 둡니다.
5. **결론 (모든 구성요소 원칙)** — 모두 개시 → "모든 구성요소 개시" / 하나라도 미개시 → "일부 미개시" / 그 밖 → "추가 검토 필요". 구성요소별 판단을 뒤집는 결론을 쓰지 않습니다.
6. **균등은 표시만** — 다른 수단이지만 같은 기능·효과로 보이면 `equivalent_check: true`로 표시하고, 균등 성립 여부는 판단하지 않습니다.
7. **점검** — 코드를 실행할 수 있으면 `python scripts/chart_check.py verify 차트.md --target 대상문서 --elements n`으로 인용문이 원문에 있는지, 결론이 규칙과 맞는지 확인하고, 실패가 있으면 고쳐서 다시 냅니다.

## 3. 대조군으로 먼저 확인 (선택, 새 분야·새 모델일 때)

본 분석 전에 같은 청구항으로 두 번 시험합니다.
- **양성 대조**: 관심 특허 자신의 발명의 설명 → 대부분 `개시`가 나와야 합니다.
- **음성 대조**: 기술 분야가 다른 무작위 특허의 설명 → 대부분 `미개시`가 나와야 합니다.
둘 중 하나라도 기대와 다르면 분설이나 용어 해석부터 다시 봅니다.

## 4. 출력

먼저 사람이 읽는 표를, 이어서 점검용 JSON을 냅니다.

| 구성요소 | 판단 | 대상 문서 근거 [식별번호] | 이유 |
|---|---|---|---|

```json
{"purpose": "FTO(침해 위험)", "claim": "문헌번호 청구항 n", "elements": [
  {"id": "E1", "status": "개시", "evidence": [{"para": "0002", "quote": "원문 그대로"}], "reason": "한두 문장", "equivalent_check": false}
 ],
 "verdict": "모든 구성요소 개시 | 일부 미개시 | 추가 검토 필요"}
```

## 5. 지켜야 할 것

- 이 차트는 **변리사 검토를 위한 1차 자료**입니다. 침해·무효·특허성에 대한 법률 의견으로 쓰지 않으며, 마지막 줄에 그렇게 적습니다.
- 대상 문서는 문서에 적힌 내용만 근거로 합니다. 실제 제품의 동작은 별도 확인이 필요하다고 적습니다.
- 인용은 원문 그대로. 중간을 생략하거나 바꿔 쓰면 점검에서 실패합니다.
- 기밀 자료(미공개 제품 사양·사내 문서)는 사용자 조직이 허용한 환경에서만 다룹니다.

> 이 클레임 차트는 문서에 기재된 내용을 비교한 1차 검토 자료이며 법률 의견이 아닙니다. 최종 판단은 변리사가 합니다.
