# 지식 노트북 6개 — 소스와 요청문

NotebookLM에 니치(niche)별로 노트북 6개를 만들고, 소스를 넣은 뒤 아래 요청문을 채팅에 보냅니다.
받은 보고서는 `knowledge/` 폴더의 같은 번호 파일에 붙여 넣습니다. 그 파일들이 두 스킬의 참고 자료가 됩니다.

- `{니치}`는 보내기 전에 바꿉니다. 예: `사회초년생 재테크`, `한국사 다큐멘터리`, `AI 도구 튜토리얼`
- 요청문은 한국어로 써도 됩니다. 영어 항목명은 괄호에 함께 두어 보고서끼리 제목이 일정하게 나오게 했습니다.
- 갱신 주기: 1~3번은 60~90일마다, 4~5번은 니치를 바꿀 때, 6번은 도구를 바꾸거나 모델이 교체될 때.

## 조사 단계와 보고 단계를 나눕니다

2·4·5번처럼 자료를 모아야 하는 노트북은 두 단계로 돌립니다.

1. **조사** — NotebookLM의 소스 찾기에서 Deep Research를 골라 조사 주제를 넣고, 찾은 소스 중 믿을 만한 것만 노트북에 가져옵니다.
2. **보고** — 소스가 들어간 뒤 채팅에 아래 보고 요청문을 보냅니다.

조사와 보고를 한 문장으로 같이 시키면 어떤 소스를 근거로 썼는지 흐려집니다. 소스를 먼저 눈으로 고르면 보고서의 근거를 나중에 되짚을 수 있습니다.

---

## 노트북 1 · 경쟁 영상 분석 (Competitor Research)

**소스**: 니치에서 조회수와 반응이 가장 좋은 영상 8~10개의 유튜브 URL
**역할**: 목표 영상 길이를 데이터로 정하는 유일한 노트북. 오프닝, 구조, 이탈 위험, 콘텐츠 공백을 뽑습니다.

```
소스로 넣은 영상은 내 니치에서 성과가 가장 좋은 영상들이다. 무엇이 이 영상들을 성공하게 했는지 분석해서 구조화된 경쟁 분석 보고서를 만들어 줘.

다음 항목을 뽑아 줘.
1. 영상 길이 (VIDEO LENGTH) — 영상별 길이 목록, 평균, 그리고 목표 길이 하나를 이유와 함께 추천
2. 오프닝 (OPENINGS) — 처음 5~10초의 공통 패턴
3. 이야기 구조 (STORY STRUCTURE) — 전형적인 전개 속도와 구조 틀
4. 전개 속도와 이탈 위험 (PACING & DROP-OFF RISK) — 주의가 끊기는 지점과 막는 방법
5. 잘 되는 주제와 관점 (WINNING TOPICS & ANGLES)
6. 이미 포화된 주제 (OVERSATURATED TOPICS)
7. 콘텐츠 공백 (CONTENT GAPS) — 아직 덜 다뤄진 기회
8. 행동 유도 방식 (CALL-TO-ACTION PATTERNS)

출력: 제목과 글머리표로 정리한 요약만. 소스에 없는 내용은 쓰지 말고, 영상별 수치는 어느 영상에서 왔는지 밝혀 줘.
```

## 노트북 2 · 시청자 심리 (Audience Psychology)

**소스**: Deep Research 보고서 + (선택) 상위 영상 3~4개의 공개 댓글 발췌
**역할**: 페르소나, 욕구, 두려움, 감정 자극 요소, 시청자가 실제로 쓰는 말

**조사 주제 (Deep Research에 넣기)**

```
유튜브에서 {니치} 영상을 보는 시청자의 심리: 누구인지, 무엇을 원하고 두려워하는지, 어떤 말과 감정에 반응하는지
```

**보고 요청문 (소스를 가져온 뒤 채팅에)**

```
소스를 바탕으로 {니치} 영상 시청자의 심리를 깊이 이해하고 싶다. 감정적으로 연결되는 영상을 만들기 위해서다. 구조화된 시청자 보고서를 만들어 줘.

1. 누구인가 (WHO THEY ARE) — 나이대, 배경, 생활 방식
2. 핵심 욕구 (CORE DESIRES)
3. 핵심 두려움 (CORE FEARS)
4. 감정 자극 요소 (EMOTIONAL TRIGGERS)
5. 그들의 말 (THEIR LANGUAGE) — 실제로 쓰는 단어와 표현 예
6. 신뢰와 의심 (TRUST & SKEPTICISM)
7. 시청 방식 (CONSUMPTION STYLE) — 선호하는 속도, 톤, 에너지
8. 참여를 부르는 것 (WHAT MAKES THEM ENGAGE)

출력: 제목과 글머리표로 정리한 요약만. 개인을 알아볼 수 있는 닉네임·인용은 빼고 경향으로만 적어 줘.
```

## 노트북 3 · 후크와 시청 유지 (Hook + Retention)

**소스**: 후크·시청 유지 심리 Deep Research 보고서 + 상위 영상 5~8개의 처음 60초 자막
**역할**: 첫 5초 구조, 오프닝 표현, 30초 구간, 끝까지 보게 하는 기법

**조사 주제**

```
짧은 영상의 첫 5초 후크와 시청 유지 심리: 열린 고리(open loop), 패턴 깨기(pattern interrupt), 되부르기(callback)
```

**보고 요청문**

```
소스는 두 가지다. (1) 후크와 시청 유지 심리에 관한 조사, (2) 내 니치 상위 영상들의 처음 60초 자막. 둘을 함께 분석해서 구조화된 후크·시청 유지 보고서를 만들어 줘.

1. 잘 되는 후크 구조 (WINNING HOOK STRUCTURES) — 자막의 실제 예와 함께
2. 오프닝 단어와 표현 (OPENING WORDS & PHRASES)
3. 첫 5초의 감정 전략 (EMOTIONAL STRATEGIES IN THE FIRST 5 SECONDS)
4. 첫 30초의 공통 구조 (THE FIRST 30 SECONDS)
5. 시청 유지 기법 (RETENTION TECHNIQUES) — 열린 고리, 패턴 깨기, 되부르기
6. 시청자가 떠나는 지점 (WHERE VIEWERS ARE LOST)
7. 끝까지 붙잡는 것 (WHAT HOLDS ATTENTION TO THE END)

출력: 제목과 글머리표로 정리한 요약만. 자막 인용은 짧게, 구조를 설명하는 데 필요한 만큼만.
```

## 노트북 4 · 영상 제작 기법 (Video Techniques)

**소스**: 니치 우수 영상의 연출·스토리텔링 기법 Deep Research 보고서
**역할**: 컷 전환 속도, 내레이션 톤, 음악, 장면 순서, 화면 요소의 기준

**조사 주제**

```
성공한 {니치} 유튜브 영상의 제작·스토리텔링 기법: 컷 속도, 내레이션, 음악, 전환, 자막·그래픽
```

**보고 요청문**

```
소스를 바탕으로 성공한 {니치} 영상의 제작 기법을 정리해 줘. 내 영상이 시청자가 기대하는 품질과 느낌에 맞도록 하려는 것이다.

1. 전개 속도 (PACING) — 컷 빈도와 리듬
2. 내레이션 방식 (NARRATION STYLE) — 톤, 문장 길이, 속도
3. 음악 사용 (MUSIC USAGE)
4. 장면 순서 (VISUAL SEQUENCING)
5. 전환 (TRANSITIONS)
6. 화면 요소 (ON-SCREEN ELEMENTS) — 자막, 그래픽
7. 기대되는 제작 품질 (EXPECTED PRODUCTION QUALITY)
8. 이 니치만의 기법 (NICHE-SPECIFIC TECHNIQUES)

출력: 제목과 글머리표로 정리한 요약만.
```

## 노트북 5 · 시각적 정체성 (Visual Identity)

**소스**: 니치에서 인기 있는 비주얼 스타일 Deep Research 보고서
**역할**: 주된 스타일, 색, 조명, 구도, 분위기, 피할 것

**조사 주제**

```
성공한 {니치} 유튜브 영상에서 가장 많이 쓰는 비주얼 스타일: 색, 조명, 구도, 분위기, 최근 경향
```

**보고 요청문**

```
소스를 바탕으로 {니치} 시청자에게 통하는 비주얼 스타일을 정리해 줘. 생성한 이미지와 클립이 이 니치에 자연스럽게 어울리게 하려는 것이다.

1. 주된 비주얼 스타일 (DOMINANT VISUAL STYLE) — 시네마틱, 사실적 사진풍, 3D 등
2. 통하는 이유 (WHY IT WORKS)
3. 색 팔레트 (COLOR PALETTE)
4. 조명 (LIGHTING STYLE)
5. 숏과 카메라 선호 (SHOT & CAMERA PREFERENCES)
6. 분위기 (MOOD & ATMOSPHERE)
7. 피할 것 (WHAT TO AVOID)
8. 떠오르는 경향 (EMERGING TRENDS)

출력: 제목과 글머리표로 정리한 요약만. 마지막에 이미지 프롬프트 끝에 붙일 영어 스타일 문구 한 줄을 제안해 줘.
```

## 노트북 6 · AI 도구 프롬프트 용어 (AI Tool Prompt Terms)

**소스**: 실제로 쓸 이미지·영상·음성 도구의 **공식** 프롬프트 가이드(PDF·웹 페이지)
**역할**: 도구가 가장 잘 알아듣는 프롬프트 구조, 카메라 용어, 기술 값

```
내가 영상을 만들 때 쓸 AI 도구들의 공식 프롬프트 가이드를 소스로 넣었다. 도구마다 구조화된 프롬프트 참고표를 만들어 줘.

도구마다 다음을 뽑아 줘.
1. 도구 이름과 용도 (TOOL NAME & PURPOSE)
2. 스타일 키워드 (STYLE KEYWORDS)
3. 기술 값 (TECHNICAL PARAMETERS) — 화면비, 고를 수 있는 클립 길이, 해상도, 움직임 세기
4. 카메라와 움직임 용어 (CAMERA & MOTION LANGUAGE)
5. 조명과 분위기 어휘 (LIGHTING & MOOD VOCABULARY)
6. 권장 프롬프트 구조 (RECOMMENDED PROMPT STRUCTURE)
7. 피할 것 (WHAT TO AVOID)

출력: 도구별로 나눈 요약만. 맨 위에 각 가이드의 날짜나 모델 버전을 적어 줘. 소스에 없는 값은 비워 둬.
```

모델이 교체되면(예: Flow의 Veo 3.1 Fast·Quality는 2026-12-05 종료) 해당 가이드를 새 모델 것으로 바꾸고 이 보고서를 다시 받습니다.

## 주의할 점

- **유튜브 URL 소스**: NotebookLM은 공개 영상의 자막을 읽습니다. 자막이 없는 영상은 내용이 비어 들어오므로 소스 미리보기에서 확인합니다. 분석은 패턴을 배우는 데 쓰고, 다른 사람의 대본·연출을 그대로 옮기지 않습니다.
- **댓글**: 닉네임 같은 개인 정보는 지우고 넣습니다. 보고서에는 경향만 남깁니다.
- **같은 계정**: Gemini에서 노트북을 연결해 쓰려면 Gemini와 NotebookLM이 같은 Google 계정이어야 합니다.
