# Copilot Studio 에이전트 만들기

## 준비물
- `agent-instructions.md` (이 폴더) — 설명, 지침, 공식 법원 사이트 목록
- `../knowledge/` 의 3개 파일 — case-rules.md, research.md, output-template.md
- (선택) 교재·논문·판결문 PDF를 모아 둔 SharePoint 폴더

## 순서
1. copilotstudio.microsoft.com → 홈에서 에이전트 만들기 → 이름: **판례 원문 조사·심층 해설**
2. Overview 의 **Description** 에 "에이전트 설명", **Instructions** 에 "지침" 전체를 붙여 넣습니다.
3. **Knowledge** → Add → 지식 파일 3개를 올리고, agent-instructions.md 표의 **공식 법원 사이트**를 공개 웹사이트로 추가합니다. 교재·판결문이 있는 SharePoint 폴더도 추가할 수 있습니다.
4. 아래 **추천 프롬프트**를 등록합니다.
5. 오른쪽 테스트 창에서 `../sample/textbook-excerpt.md` 내용을 붙여 넣고 시험합니다. 헤더 7개 · 11개 항목 · 8번 심급 표가 나오면 정상입니다.
6. **Publish** → **Channels** → Microsoft 365 and Microsoft Teams 로 팀에 배포합니다.

## 추천 프롬프트
| 제목 | 프롬프트 |
|---|---|
| 교재 판례 해설 | 첨부한 교재 문단에 인용된 판례를 모두 찾아 목록표를 만들고, 첫 번째 판례부터 심층 해설해 줘 |
| 특정 판례 해설 | [사건명·사건번호]를 공식 원문으로 조사해서 11개 항목으로 해설해 줘 |
| 심급 이력만 | [사건명]의 제1심부터 최종심까지 심급 표만 만들어 줘. 확인 못 한 칸은 미확인으로 |
| 교재 대조만 | 첨부한 교재 문구와 [사건명] 판결 원문을 대조해 일치·생략·보완 표를 만들어 줘 |

## 참고
- 지침 칸이 짧게 제한되는 환경이면 1·4·5·7·10번만 남기고 나머지는 지식 파일(case-rules.md)에 맡기세요.
- 웹 검색 사용 여부, 메뉴 이름은 회사 라이선스·관리자 설정에 따라 다를 수 있습니다.
