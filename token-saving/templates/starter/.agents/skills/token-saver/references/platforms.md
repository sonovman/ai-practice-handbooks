## 공통 원칙
- 길어진 세션은 비우고, 반복 배경은 재사용 구조로. 모델·설정은 시작에 고정.
- 출력이 흔히 더 비싸다 — 간결한 출력·낮은 사고 예산으로 단순 작업 비용을 줄인다.
- 비용은 모델·요금제에 따라 다르니 각 도구의 현재 단가·사용량 페이지로 확인.

- Antigravity(핸드북 16편)에 "슬림 CLAUDE.md·터미널 출력 요약·세션 시작 체크리스트를 갖춘 하네스를
  구성해 줘"처럼 재사용 구조의 초안을 맡기고, 적용·검증은 사람이 한다.

## 주의
- 단가·슬래시 명령·캐시 정책은 자주 바뀐다. 적용 전 각 도구의 공식 문서·요금표로 확인한다.
- 검증 안 된 외부 스킬·스크립트는 프롬프트 주입·정보 유출 위험. 출처 확인·deny/샌드박스 설정.
