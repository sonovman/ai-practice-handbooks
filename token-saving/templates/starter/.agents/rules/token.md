# 토큰·비용 절약 작업 흐름(모델 판단 시 적용)

1. 원인 진단: 매 턴 재전송·노이즈·출력/사고 토큰·캐시 깨짐.
2. 숫자 먼저: token_cost.py(단건)·session_sim.py(세션)로 어디서 나가는지 확인.
3. 세션: 전환 시 /clear, 설정은 시작 고정, 방향 틀어지면 /rewind, /context로 MCP 정리, /usage로 분석.
4. 입력: @멘션 지목, 오류 위치 명확, 터미널 출력 짧게.
5. 캐시: 앞부분 고정으로 캐시 읽기 활용(모델·에포트 중간 변경 금지).
6. 외부 출력절감 스킬: 효과·한계·보안 확인 후. 짧은 대화엔 역효과.

주의: 단가·명령·캐시 정책은 자주 바뀜. 공식 문서·요금표로 확인. 미검증 스킬은 보안 위험.
