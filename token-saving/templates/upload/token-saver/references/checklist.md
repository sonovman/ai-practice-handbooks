# 토큰 절약 체크리스트

## 슬래시 명령 요약
| 명령 | 용도 |
|---|---|
| /clear | 대화·컨텍스트 비우기(작업 전환 시) |
| /context | 무엇이 창을 차지하나 확인, 안 쓰는 MCP·플러그인 정리 |
| /rewind | 방향이 틀어졌을 때 이전 턴으로 되돌리기(재시작 없이) |
| /usage | 최근 토큰 소모(스킬·MCP·플러그인별) 분석 |
(명령·동작은 버전에 따라 다를 수 있으니 /help 로 현재 명령을 확인)

## 세션·캐시
- [ ] 작업/주제 전환 시 /clear
- [ ] 모델·에포트는 세션 시작에 고정(중간 변경 = 캐시 깨짐)
- [ ] 방향 틀어지면 /rewind
- [ ] 반복 배경은 하네스(슬림 CLAUDE.md·스킬)로 재사용

## 입력·컨텍스트
- [ ] 파일은 @멘션으로 지목(불필요한 탐색 토큰 절감)
- [ ] 오류는 "테스트 실패" 대신 파일·위치를 정확히
- [ ] /context 로 안 쓰는 MCP·플러그인 끄기
- [ ] 긴 터미널 출력은 필요한 것만 짧게(요약 옵션·스크립트)

## 출력·사고 토큰
- [ ] 단순 작업은 에포트/사고 예산을 낮춰(max_thinking_tokens 등)
- [ ] 출력을 줄이는 외부 스킬은 보안·효과를 확인 후, 짧은 대화엔 역효과 주의
- [ ] token_cost.py·session_sim.py 로 '어디서 돈이 나가는지' 먼저 확인
