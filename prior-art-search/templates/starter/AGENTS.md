# AGENTS.md — 이 폴더에서 에이전트가 항상 지킬 것

이 폴더는 핸드북 28편 '선행기술조사(검색식→검색→최근접 선행문헌)' 키트입니다.

## 항상
- 한국어, 초보자도 따라 하기 쉽게 단계별로.
- 판단(근거와 함께 기록)과 집계(공개 규칙으로 계산)를 분리한다.
- 구성대비는 특징별 ●/◐/○에 **근거 위치**를 반드시 적는다(없으면 산정 중단).
- 최종 법적 판단(신규성·진보성·FTO)은 변리사가 한다. AI는 1차 초안.

## 약관·보안
- 웹 DB는 브라우저 자동화로 반복 조회하지 않는다(약관 위반). 사람이 링크/식을 실행.
- 공식 API만 자동(KIPRIS Plus·OPS·BigQuery). 불명의 외부 중계 서버로 데이터 전송 금지.
- API 명령은 먼저 dry-run으로 호출량·처리량을 확인한 뒤 실행.

## 날짜 기준
- 신규성용은 cutoff 이전으로 한정. 확대된 선출원(제29조 제3항)·선출원(제36조)은 cutoff 없는 KR 검색도.

## 도구(표준 라이브러리)
- `tools/build_queries.py` — 개념 조사식 → DB별 검색식·URL.
- `tools/rank_closest.py` — 구성대비(mapping.json) → 최근접 선행문헌 산정.
- 시험: `python tools/test_build_queries.py`, `python tools/test_rank_closest.py`.
