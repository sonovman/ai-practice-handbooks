# 선행기술조사 작업 흐름(모델 판단 시 적용)

1. 접수: 청구항·우선일(cutoff)·목적 확인, 빠진 정보는 하나만 질문.
2. 개념 조사식(plan.json): 특징 분해·차별 특징 표시·다국어 키워드.
3. 검색식(G1): build_queries.py로 DB별 식·URL. 승인 후 진행.
4. 검색(G2): 공식 API는 호출량 확인 후 자동, 웹 DB는 사람이 실행(브라우저 자동화 금지).
5. 구성대비: 특징별 ●/◐/○ + 근거 위치를 mapping.json에.
6. 산정(G4): rank_closest.py로 점수·분류(A/B/C/X)·결합 경로. 근거 없으면 중단.
7. 보고·보충 검색(빈 특징만, 최대 2회).

주의: 웹 DB 약관 준수. cutoff 날짜 기준 주의(확대선출원은 cutoff 없는 KR도). 최종 판단은 변리사.
