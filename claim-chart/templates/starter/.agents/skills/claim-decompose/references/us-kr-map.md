# 미국 ↔ 한국 개념 대응표

분해·대비의 사고방식은 같습니다. 제도·용어·판단 기준이 다른 곳만 표시했습니다. 조문·판례는 개념 안내이며 사건별 확인이 필요합니다.

| 개념 | 미국 | 한국 | 같은 점 / 다른 점 |
|---|---|---|---|
| 비교 단위 | limitation / element | 구성요소(구성) | 같음: 청구항을 구성으로 나눠 1:1 대비 |
| 전구성요소 원칙 | All-Elements Rule | 구성요소 완비의 원칙 | 같음: 하나라도 없으면 문언침해 아님 |
| 대비 문서 | Claim Chart(LPR 침해·무효 주장서) | 청구항 대비표(침해소송·권리범위확인심판·무효심판) | 한국엔 LPR 같은 정형 제출 규칙이 없으나 실무상 대비표를 조기 제출. 늦은 주장은 민사소송법 제149조(실기한 공격·방어방법 각하) 위험 |
| 해석 기준 | *Phillips*: 통상의 기술자가 명세서·출원경과에 비춰 이해하는 의미 | 청구범위 기재 기준, 발명의 설명·도면 참작(문언 제한·확장 해석 금지) | 같음: 내재적 기록 중심. 상세는 다음 편 '청구범위 해석' |
| 균등론 | Graver Tank 기능·방식·결과(FWR) / 비본질적 차이, 한정별 적용(*Warner-Jenkinson*) | 판례 요건: 과제해결원리 동일, 실질적 같은 작용효과, 치환 용이성, 공지기술에서 용이하게 도출 아님, 출원경과상 의식적 제외 없음 | '방식(Way)'과 '과제해결원리'가 핵심이라는 점에서 닮음. 과제해결원리는 명세서·공지기술을 참작해 실질적으로 파악(대법원 2014. 7. 24. 선고 2013다14361; 2019. 1. 31. 선고 2017후424) |
| 출원경과 금반언 | *Festo*: 특허성 관련 축소 보정 → 포기 추정(예측불가·주변적 관련·기타 사유로 번복) | 의식적 제외(균등 소극 요건) | 같음: 보정·의견서로 뺀 범위는 되찾기 어려움 |
| 공중헌납 | *Johnson & Johnston* (en banc 2002) | 명시 법리 없음(사안별 주장 가능) | 명세서에만 쓰고 청구하지 않은 대안 주의 |
| 기능식 청구항 | §112(f): 명세서 SAM + 균등물로 한정 | 기능적 표현 허용(특허법 제42조 제6항), 명문 축소 규정 없음 — 명세서 참작 해석 | 미국식 SAM 자동 축소를 그대로 옮기지 말 것 |
| 신규성 | §102: 단일 문헌이 모든 한정을 명시·내재적으로 개시 | 제29조 제1항 | 같음: 단일 문헌 원칙 |
| 진보성 | §103: 청구발명 전체, *Graham* 요소, *KSR* 결합 동기·합리적 성공 기대 | 제29조 제2항: 통상의 기술자가 쉽게 발명할 수 있는지 | 같음: 결합의 논리·사후고찰 금지 |
| 공지 예외(유예) | AIA §102(b)(1): 발명자 측 공개 1년 | 제30조: 12개월 | 기간은 같으나 요건·절차 다름 |
| 간접침해 | §271(b) 유도, §271(c) 기여 | 제127조(전용물 등) | 한국은 '유도침해' 명문 규정이 없음 |
| 권리범위 확인 | (해당 제도 없음) | 권리범위확인심판(제135조) | 확인대상발명 특정이 차트의 '대상물 특정'과 같은 역할 |
