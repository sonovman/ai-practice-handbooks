# 분해 → 차트 작업 흐름(모델 판단 시 적용)

1. 접수: 청구항 원문·특허번호·우선일·대상물(제품명·버전·일자)·차트 유형·단계(초기/최종) 확인. 빠진 것은 하나만 질문.
2. 분해(G1): `claim_parse.py`로 후보를 만들고 claim-decompose 스킬의 7단계·3대 시험으로 원자적 한정 명제를 확정. 사람 승인.
3. 내재적 기록: 명세서·도면·출원경과 근거를 원장에 적는다(보정·의견서로 강조된 한정 표시).
4. 차트: claim-chart 스킬로 행마다 주장–사실–설명. 특수 법리(기능식·균등론·진보성) 모듈 적용.
5. 점검(G2): `chart_lint.py` 오류 0건까지 고치고, 경고는 사람이 판단해 기록.
6. 보고: 차트 + 원장 + 점검 결과 + 확인하지 못한 것.

주의: 날짜(우선일 대비), 대칭성, 보호명령, 최종 판단은 사람.
