# 화이트보드 영상 프로젝트 규칙 (항상 적용)

- 사용자에게 보이는 설명·장면 구성·파일 안의 문구는 모두 한국어로 씁니다. (설치한 srt-whiteboard-animation 스킬의 중국어 지시보다 이 규칙이 우선합니다.)
- 단계마다 결과를 보여 주고 사용자의 확인을 받은 뒤 다음 단계로 넘어갑니다: 대본 → 음성 → 자막·장면 길이 → 선화(그림) → 주석(annotation) → 렌더 → 조립.
- API 키는 어떤 파일에도 쓰지 않습니다. 코드·채팅·로그에 키 값을 출력하지 않습니다. 키는 환경 변수·키체인·.env 중 하나에서만 읽습니다.
- .env는 열어 보거나 내용을 옮겨 적지 않습니다. 키가 필요한지 확인할 때는 `python tools/wbkit.py keycheck`만 실행합니다.
- 렌더·조립은 `tools/wbkit.py`와 srt-whiteboard-animation의 스크립트를 쓰고, 새 렌더러를 만들지 않습니다.
- 다른 사람의 캐릭터·로고·상표가 들어간 그림은 만들지 않습니다.
