# 초보자 3단계 체크리스트와 자가 진단

## 오늘 당장 3단계
1. **프라이버시 설정** — 데스크톱 앱 설치 → 설정에서 'AI 모델 개선 돕기' 끄기.
2. **작업 폴더 + CLAUDE.md** — 전용 폴더 만들고 `claude_md_init.py`로 안내 책자 초안 생성 → ✏️ 채우기.
3. **반복 업무 1개 스킬화** — 자주 치던 지시문 하나를 `skill_init.py`로 스킬로 고정.

## 자가 진단(스스로 답해 보기)
- Q. 파일·폴더로 '실제 작업'을 시키려면 무엇이 켜져 있어야 하나? → 데스크톱 앱이 열려 있어야 로컬 파일·브라우저·컴퓨터 제어가 된다.
- Q. 대화가 길수록 품질이 떨어지는 이유와 해법? → 컨텍스트(책상)가 비대·오염되기 때문. /compact·/clear, ESC 두 번(Rewind), 새 대화.
- Q. CLAUDE.md의 바람직한 분량? → 150~200줄 안쪽의 안내 책자. 자세한 건 참조 문서로.
- Q. 예스맨·환각을 막는 장치? → 비판 요청(악마의 대변인) + 실행/테스트 증거 요구(자가 검증 게이트).
- Q. 회사에서 보안 3원칙? → ① 'AI 모델 개선 돕기' 끄기 ② 문서 첨부 시 개인정보 칼럼 삭제·가명화 ③ 민감 업무는 유령 모드.

## 흔한 실수(피하기)
- 처음부터 스킬·도구 전면 설치 → 책상만 복잡. 바닐라로 시작해 하나씩.
- "알아서 다 해줘"식 포괄 지시 → 목적·완료 기준은 사람이 준다.
- 한 대화창에서 계속 작업 → 주기적으로 책상 정리.
- 실패 기록을 남긴 채 "B로 해줘" → Rewind로 깨끗한 시점에서 재시도.
