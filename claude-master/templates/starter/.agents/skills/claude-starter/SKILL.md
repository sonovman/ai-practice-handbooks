# Claude 시작 세팅(초보자용)

Claude를 처음 업무에 붙이는 사람이, 작은 성공을 빠르게 만들도록 돕는다.
원칙: 한꺼번에 다 깔지 말 것. 바닐라(기본)로 시작해, 불편이 반복될 때 하나씩 추가한다.

## 0. 프라이버시 먼저
- 설정 → 개인정보 보호에서 'AI 모델 개선 돕기'를 끈다(대화가 학습에 쓰이지 않게).
- 민감 업무는 기록이 남지 않는 유령 모드(Incognito)를 쓴다. 단, 유령 모드는 파일 생성·코드 실행이 안 되니 참고.
- 문서를 붙일 때 이름·연락처 등 개인정보 칼럼은 미리 지우거나 가명으로.

## 1. 작업 폴더와 안내 책자(Second Brain)
- 실험용 전용 폴더를 하나 만든다.
- 그 폴더에 CLAUDE.md(안내 책자)를 둔다. 150~200줄 안쪽으로 짧게, 자세한 건 INDEX.md나 세부 문서로.
- 초안은 `tools/claude_md_init.py <폴더> --write` 로 자동 생성한 뒤 ✏️ 자리를 채운다.

## 2. 반복 업무 1개를 스킬로(Skills)
- 매번 길게 치던 지시문/서식 변환을 스킬로 고정한다.
- 뼈대는 `tools/skill_init.py <이름> --desc "언제 쓰는지"` 로 만든다.
- description(언제 쓰는지)이 핵심이다. 200자 이내로 또렷하게.

## 3. 책상(컨텍스트) 관리
- 새 주제는 새 대화로 시작한다. 길어지면 /compact(압축), 바뀌면 /clear(비우기).
- 잘못된 방향으로 가면 입력창에서 ESC 두 번(Rewind)으로 깨끗했던 시점으로 되돌아간다.
- 세션을 비우기 전 "지금까지 정한 것과 다음 할 일을 인수인계 문서로 정리해 줘"로 기억을 남긴다.

## 4. 예스맨 방지(검증)
- 결과를 그대로 믿지 말 것. "이 안의 약점을 투자자 관점에서 공격해 줘"처럼 비판을 시킨다.
- 코드는 "직접 실행해 결과(또는 테스트 통과)를 증거로 보여줘"라고 완료 기준을 준다.
