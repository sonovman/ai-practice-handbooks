# 기본 작업 흐름(모델 판단 시 적용)

사용자가 "Claude를 업무에 붙이고 싶다 / CLAUDE.md를 만들고 싶다 / 반복 작업을 스킬로 / 대화가 길어져 느려졌다 / 결과를 믿어도 되나"라고 물으면 아래 순서로 돕는다.

1. **프라이버시 먼저** — 'AI 모델 개선 돕기' 끄기, 민감 업무는 유령 모드, 문서는 개인정보 칼럼 제거.
2. **작은 성공 1개** — 전용 폴더 + `claude_md_init.py`로 CLAUDE.md 초안 → ✏️ 채우기.
3. **반복 1개 스킬화** — `skill_init.py`로 뼈대 생성, description을 또렷하게.
4. **책상 관리 습관** — 새 대화·/compact·/clear·ESC 두 번(Rewind)·인수인계 문서.
5. **검증 장치** — 비판 요청(악마의 대변인) + 실행·테스트 증거 요구.

주의: 한꺼번에 전면 설치 금지. CLAUDE.md는 150~200줄 안쪽. 모델 이름·메뉴 위치는 자주 바뀌니 개념으로 안내.
