# 기호 약속표 (팀 공통)

| 기호 | 약속 | 예 | 하지 않는 것 |
|---|---|---|---|
| `#` `##` | 섹션 제목 | `# 역할` `# 조건` `# 출력 형식` | 한 프롬프트에서 섹션을 #와 XML로 번갈아 나누기 |
| `1.` `2.` | 순서가 있는 작업 단계 | `1. 요청을 찾는다` | 순서 없는 조건에 번호 붙이기 |
| `-` | 순서 없는 조건·항목 | `- 톤: {톤}` | `-`와 `*`를 섞어 목록 만들기 |
| `**굵게**` | 정말 중요한 1~2곳 | `**금요일까지 회신**` | 문장마다 굵게, 대문자·'절대' 남발 |
| `{변수}` | 보내기 전에 사람이 채울 값 | `{수신자}` | 채우지 않은 채 보내기, 변수 안에 선택지 넣기 |
| `<태그>…</태그>` | 붙여 넣는 자료의 경계 | `<받은메일>…</받은메일>` | 꺾쇠를 빈칸 표시로 쓰기 (`<이름>`) |
| `[A / B / C]` | 고를 수 있는 값의 목록 | `[정중한 / 간결한]` | 누가 고르는지 말하지 않기 |
| `"…"` | 정확한 글자를 가리킴 | `"급건"이라는 단어` | 따옴표만으로 뜻 고정을 기대하기 — 뜻은 문장으로 |
| ` ``` ` | 예시·코드·원문을 통째로 감쌈 | 출력 예시 블록 | 지시문까지 블록 안에 넣기 |
