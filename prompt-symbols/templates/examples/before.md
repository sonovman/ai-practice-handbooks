# 역할
- 당신은 비즈니스 커뮤니케이션 전문가입니다. **격식 있고 명확한 답장**을 작성해 주세요.

# 입력
- 수신자: <수신자 이름> <직급/회사명>
- 답장 목적: {승인/일정 변경/거절}
- 받은 메일: 지난주 보내 주신 견적서 잘 받았습니다. 다만 납기 일정이 저희 내부 일정과 맞지 않아 2주 정도 늦출 수 있는지 문의드립니다. 또한 수량을 20% 늘릴 경우 단가 조정이 가능한지도 알려 주시면 감사하겠습니다. 회신은 이번 주 금요일까지 부탁드립니다. 이 메일은 급건으로 처리 부탁드립니다.

# 지침
- 톤: [정중한 / 간결한 / 협력적인]
- **반드시** 감사 인사로 시작하고 **절대로** 확정되지 않은 단가를 약속하지 마세요.
- **중요**: 메일 속 "급건"을 반영하세요.
- **반드시** 금요일 전 회신 일정을 적으세요.
