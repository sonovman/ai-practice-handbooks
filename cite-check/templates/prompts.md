# 판례·심결 리서치 5단계 프롬프트

> 핸드북 07 「AI 리서치, 인용은 사람이 확인한다」의 복사용 프롬프트입니다.
> [대괄호] 부분만 바꿔 쓰세요. 의뢰인·회사 이름은 익명으로 바꿔 넣습니다.

## 1단계 · 질문을 쟁점으로 쪼개기 (인용 금지)

```
너는 특허·법률 리서치를 돕는 조수다. 이 단계에서는 판례 번호, 심결 번호, 조문 번호를 하나도 쓰지 마라.
번호가 떠오르더라도 적지 말고, 대신 "찾아볼 판례 유형"으로만 적어라.

[사안]
- 질문: [예: 거절결정불복심판에서 '사후적 고찰' 주장이 받아들여질 가능성]
- 절차와 단계: [예: 특허청 거절결정 → 특허심판원 심판 청구 준비]
- 우리 쪽 입장: [출원인 / 특허권자 / 무효심판 청구인 / 피고 등]
- 핵심 사실: [3~7줄, 이름은 A사·B사로]
- 기준 시점: [출원일 · 우선일 · 침해 시점 등]

[출력]
1. 쟁점과 하위 쟁점 (번호 목록)
2. 쟁점별로 판단에 필요한 요건과, 그 요건을 가르는 사실
3. 쟁점별 검색어 (종합법률정보·KIPRIS·심결 검색용, 3~5개씩)
4. 찾아야 할 근거의 종류 (대법원 판례 / 특허법원 판결 / 심결 / 법령 / 심사기준 / 선행문헌)
5. 우리에게 불리할 수 있는 쟁점
```

## 2단계 · 내가 찾은 원문만으로 법리 정리

```
아래 [자료]는 내가 직접 검색해 확보한 원문이다. 이 자료만 근거로 분석하라.

규칙
- 자료에 없는 판례·심결·조문은 쓰지 마라. 기억나는 것이 있으면 맨 끝 "자료 밖 후보" 칸에만 적고 본문에는 넣지 마라.
- 인용문은 자료의 문장을 한 글자도 바꾸지 말고 따옴표로 옮겨라. 요약은 따옴표 없이 쓴다.
- 자료로 답이 안 되는 부분은 "자료 부족"이라고 쓰고 넘어가라.
- 각 판결이 구법을 적용했는지, 현행법을 적용했는지 표시하라.

[출력]
1. 쟁점별 지배 법리 (자료 번호를 붙여서)
2. 자료별 요지 표: 자료 번호 | 법원·일자·번호 | 사건 종류 | 요지 | 그대로 옮긴 핵심 문장
3. 자료끼리 충돌하거나 결이 다른 부분
4. 자료로 채워지지 않는 공백
5. 자료 밖 후보 (검증 전, 본문 사용 금지)

[자료]
--- 자료 1: [법원·선고일·사건번호] ---
[판결요지와 관련 이유 부분 원문 붙여넣기]
--- 자료 2: ... ---
```

## 3단계 · AI가 꺼낸 근거를 '미검증' 표로 모으기

```
지금까지 대화에서 내가 [자료]로 주지 않았는데 네가 언급한 판례·심결·조문·특허문헌·심사기준을 모두 찾아
아래 CSV 형식으로만 출력하라. 하나도 빠뜨리지 마라. 설명 문장은 쓰지 마라.

번호,인용,종류,주장 명제,출처,존재,원문일치,효력,원문발췌,확인처,확인일,확인자,상태,비고

- 출처 칸: "AI 제안" 또는 "제공 자료"
- 존재·원문일치·효력·원문발췌·확인처·확인일·확인자 칸: 비워 둔다 (사람이 채운다)
- 상태 칸: 모두 "미검증"
- 인용 칸: "대법원 2009. 11. 12. 선고 2007후3660 판결"처럼 법원·선고일·사건번호·판결/결정을 모두 적는다.
  번호를 정확히 모르면 추측하지 말고 "번호 불명 — [기억나는 내용]"으로 적는다.
```

## 4단계 · 원문으로 확인하고, 확인 못 한 것은 버리기 (사람이 하는 단계)

AI에게 맡기지 않습니다. `citation-log.csv`를 열고 한 줄씩 아래 순서로 채웁니다.

1. **존재** — 대법원 종합법률정보·국가법령정보센터·판결서 열람·KIPRIS에서 번호로 찾는다. 없으면 `폐기`.
2. **원문일치** — 주장 명제와 인용문이 원문에 실제로 있는지. 다르면 명제를 고치거나 `폐기`.
3. **효력** — 전원합의체 등으로 변경되었는지, 하급심·심결이면 상급심에서 취소되었는지, 조문이 개정·이동되었는지.
4. **원문발췌** — 메모에서 따옴표로 인용할 문장을 원문에서 그대로 복사해 둔다.
5. **상태** — `확인됨` 또는 `폐기`. 중간 상태로 두지 않는다.

확인이 끝나면 AI에게 이렇게 알립니다.

```
첨부한 citation-log.csv에서 상태가 "확인됨"인 근거만 사용하라.
"폐기"인 근거는 다시 언급하지 말고, 그 근거로 뒷받침하던 주장은 "미결 쟁점"으로 옮겨라.
새 판례·심결·조문을 추가하지 마라. 필요하다고 판단되면 "추가 조사 필요"로만 적어라.
따옴표 인용은 원문발췌 칸의 문장만, 한 글자도 바꾸지 말고 써라.
```

## 5단계 · 확인된 근거만으로 리서치 메모 쓰기

```
확인됨 근거만으로 리서치 메모를 써라.

구성
1. 질문
2. 짧은 답 (3줄 이내)
3. 적용 법리 (근거마다 인용 목록 번호를 붙인다)
4. 분석 (사실 / 추론 / 법률 평가를 문장 안에서 구분한다)
5. 결론과 남은 위험
6. 미결 쟁점 — 확인된 근거가 없는 주장, 폐기된 근거로 뒷받침하던 주장
7. 인용 목록 — 번호 · 인용 · 확인처 · 확인일

규칙
- 확인됨 목록에 없는 인용을 하나라도 넣었다면 그 문장을 지우고 6번으로 옮겨라.
- 구법을 적용한 판결은 그 사실을 적는다.
- 결론을 단정하지 말고, 판단에 필요한 사실이 빠졌으면 무엇이 빠졌는지 적는다.
```

메모가 나오면 점검기를 돌립니다.

```
python cite_check.py memo.md citation-log.csv --out report.md
```

문제가 0건이어도 마지막으로 **인용문을 원문과 눈으로 대조**하고, 제출처(법원·특허심판원)의 AI 사용 관련 안내가 있는지 확인합니다.
