템플릿 내려받기

[대괄호] 부분만 바꿔 쓰세요. 한 번에 받으려면 키트 전체(ZIP)를 받으세요.

파일내용
prompts.md5단계 프롬프트 전체본 (1 쟁점 · 2 원문 분석 · 3 미검증 표 · 4 확인 후 지시 · 5 메모)
citation-log.csv미검증 표이자 확인 목록. 상태는 미검증 → 확인됨 / 폐기 (UTF-8 BOM, 엑셀에서 바로 열림)
CLAUDE.md리서치 프로젝트 지침 — 절대 규칙 8개. 다른 AI의 지침 칸에도 그대로 사용
cite_check.py인용 점검기 — python cite_check.py memo.md citation-log.csv --out report.md
skill/cite-check/Claude 스킬 (SKILL.md + scripts/cite_check.py). 스킬 ZIP을 Claude의 Customize → Skills에 올립니다.
