# 비밀이 이미 올라갔을 때 (응급)

```
실수로 API 키가 들어간 파일을 깃허브에 올렸어. 다음을 순서대로 도와줘:
1. 가장 먼저 그 키를 제공자 사이트에서 폐기·재발급해야 한다는 점을 알려줘(이미 수집됐다고 가정).
2. 커밋 이력 전체에서 그 파일/문자열을 제거하는 방법을 git filter-repo 기준으로 알려줘(BFG 대안도).
3. 강제 푸시와, 팀원들이 재클론해야 한다는 안내.
4. 재발 방지(.gitignore, 환경 변수, GitHub Secret scanning) 체크.
이력 재작성은 되돌리기 어려우니, 실행 전에 무엇을 할지 먼저 설명해 줘.
```
