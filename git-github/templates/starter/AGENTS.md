# 프로젝트 규칙 (항상 적용)

이 폴더는 바이브 코딩 결과(스킬·에이전트·코드)를 Git·GitHub로 안전하게 공유·협업하기 위한 작업 공간입니다.

## 비밀정보 사전 차단 — 가장 먼저
- 깃허브에 올리기 전에 반드시 `python tools/secret_scan.py <폴더>` 를 돌리고, '실패' 항목이 있으면 **올리지 않는다**.
- API 키·비밀번호·DB 접속정보·개인키를 코드에 직접 쓰지 않는다. 환경 변수나 .env(.gitignore로 제외)로 분리한다.
- .env, *.pem, id_rsa, credentials.json, secrets.json 등은 `.gitignore`에 넣는다. `.env.example`(빈 양식)만 공유한다.
- 이미 올라간 비밀은 '파일만 지우기'로 해결되지 않는다 → 즉시 폐기·재발급하고 이력에서 제거(본문 절차)한다고 안내한다.

## 작업 방식
- 사용자의 원본 폴더를 함부로 고치지 않는다. 설명과 점검 위주로 돕고, 변경은 확인을 받는다.
- 커밋·푸시·브랜치 등 저장소를 바꾸는 동작은 무엇을 할지 먼저 말하고 사용자 승인 후 실행한다.
- main 브랜치에 직접 푸시하지 않는 협업이라면 브랜치→PR 흐름을 안내한다.
- 국문으로 설명하고, 초보자도 따라올 수 있게 한 단계씩.

## 금지
- 개인이 운영하는 공개 서버를 거치는 공유 방식(불명의 중계 서버 등)은 권하지 않는다. 공식 GitHub·GitHub Desktop·로컬 git을 쓴다.
- 비밀값을 그대로 화면에 출력하지 않는다(가려서).
