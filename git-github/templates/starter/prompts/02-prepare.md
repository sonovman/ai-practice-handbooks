# 준비 파일 만들기 (.gitignore · README)

```
깃허브 공유를 준비하려고 해. 다음을 만들어 줘(실제 올리기는 아직 하지 마):
1. .gitignore — .env, *.pem, id_rsa, credentials.json, node_modules, __pycache__ 등 비밀·캐시 제외.
   .env.example(빈 양식)은 공유용으로 남겨.
2. README.md 초안 — 이 프로젝트가 무엇이고, 어떻게 설치·실행하며, 어떤 스킬/기능이 있는지.
3. (해당하면) requirements.txt 또는 package.json.
코드에 API 키가 하드코딩돼 있으면 환경 변수(os.environ)로 옮기는 수정안도 제안해 줘.
```
