# 청구범위 해석

목표: 승패를 가르는 다툼 용어의 의미와 경계를 **근거와 함께** 정하고, 그 결과를 한정 원장·Claim Chart에 반영한다.
원칙: 해석하되 다시 쓰지 않는다. 청구항 문언이 출발점이다.

## 1. 먼저 정할 것
- 절차 → 기준: 법원·ITC·PTAB(2018. 11. 13. 이후 청구) = **Phillips** / 심사·재심사·재발행 = **BRI**(명세서와 부합하는 가장 넓은 합리적 해석) / 한국 = 청구범위 기재 기준, 발명의 설명·도면 참작, 제한·확장 해석 금지.
- 어떤 용어를 해석할지: 당사자가 범위를 다투고 그 다툼이 결론을 바꾸는 용어는 반드시 경계를 정한다. 결론과 무관한 용어는 정하지 않아도 된다.

## 2. 용어별 절차 (해석표 한 줄 = 한 용어)
1. 문언: 그 청구항과 다른 청구항에서의 쓰임(같은 용어는 같은 의미 추정), 종속항과의 관계(청구항 차별화).
2. 명세서·도면: 명시적 정의(자기 사전)가 있는가 / 발명 전체를 한정하는 명백한 포기("본 발명은 반드시 …")가 있는가 / 아니면 실시예일 뿐인가(실시예는 끌어들이지 않음, 유일한 실시예라도).
3. 출원경과: 거절 극복을 위한 진술·보정. '명백하고 확실한' 포기만 범위를 줄인다. IPR 등에서 특허권자의 진술도 포함.
4. 외재적 증거: 사전·전문가 증언은 배경 이해용. 내재적 기록과 충돌하면 쓰지 않는다.
5. 결론: 해석 문장 + 근거 위치 + 침해·유효성 양쪽에 같은 해석.

## 3. 특수 형식
- 기능식(§112(f)): ① 청구된 기능 특정 ② 명세서의 대응 구조(소프트웨어는 알고리즘)와 그 균등물. 구조가 없으면 불명확성. 'means' 없는 module·unit도 해당할 수 있음. 한국은 자동 축소 규칙 없음.
- 전제부: 원칙적으로 비한정. 본문의 선행사 제공·출원경과 의존·Jepson·발명에 생명을 주는 경우 한정.
- 전환구: comprising(개방) / consisting of(폐쇄) / consisting essentially of(기본적·신규 특성에 실질 영향 없는 추가만).
- 제법한정물건: 미국 = 침해에서는 제법이 한정, 유효성은 물건 자체 / 한국 = 특허요건·침해 모두 물건 자체(명백히 불합리하면 예외).
- 방법 단계 순서: 문언·논리상 필요할 때만 순서 한정.
- 정도 표현(substantially 등): 명세서가 주는 객관적 기준이 있으면 명확.
- 겉보기 모순: 한정은 누적 조건으로 읽고, 기술적으로 말이 되는 해석을 찾되 청구항을 다시 쓰지는 않는다.

## 4. 명확성(§112(b))
- 순서: 해석 먼저 → 그다음 원래 문언이 통상의 기술자에게 범위를 '합리적 확실성'으로 알리는지.
- 청구항에 없는 말을 해석에 넣고 그 말 때문에 불명확하다고 하지 않는다. 의미에 합의했다고 명확성이 자동 충족되지 않는다.

## 5. 절차 점검
- 항소: 원심에서 내지 않은 새 해석은 실권. 기존 주장의 정교화는 가능. 심판원이 통지 없이 새 해석을 채택했다면 예외.
- 심사 기준: 해석 결론(내재적 증거) = 전면 재심사 / 외재적 증거에 기초한 사실인정 = 명백한 오류.
