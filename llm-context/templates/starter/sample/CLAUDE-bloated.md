# 프로젝트 지침

우리 프로젝트는 매우 중요하므로 항상 신중히 처리해 주세요.
코드는 깨끗한 코드로, 가독성 좋게, 주석을 잘 달아서 작성합니다.
변수명을 잘 짓고, 네이밍을 잘 하고, 최대한 클린하게 유지하세요.
가능한 한 테스트를 작성하는 것이 좋고, 문서화를 잘 해주세요.
보안에 유의하고, 에러를 잘 처리하고, 적절히 예외를 다루세요.
성실하게, 알아서 센스 있게 베스트 프랙티스를 따라 주세요.

1. 기능을 구현할 때는 사용자 경험을 신중히 고려한다.
2. 코드 리뷰는 꼼꼼하게 한다.
3. 커밋 메시지는 명확하게 작성한다.
4. 변수는 의미 있게 짓는다.
5. 함수는 짧게 유지한다.
6. 중복 코드를 피한다.
7. 매직 넘버를 쓰지 않는다.
8. 주석을 적절히 단다.
9. 테스트 커버리지를 높게 유지한다.
10. 가독성을 최우선으로 한다.
11. 린트 규칙을 지킨다.
12. 타입을 명시한다.
