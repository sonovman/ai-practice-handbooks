IP 분석 템플릿 내려받기

파일 이름을 누르면 내용을 볼 수 있고, 오른쪽 버튼으로 내려받을 수 있습니다. 앞의 세 개만으로도 시작할 수 있습니다.

기본 (누구나)

파일쓰는 곳
CLAUDE.md하네스 · 에이전트가 가장 먼저 읽는 IP 분석 업무 지침받기
ip-reviewer-prompt.md루프 · 독립 IP 리뷰어에게 주는 검수 프롬프트받기
claim-chart-template.md결과물 · 청구항 대비표 빈 양식받기
claim-chart-example.md결과물 · 가상 사례로 채운 대비표 예시받기

고급 (Claude Code 사용자)

파일쓰는 곳
check_claim_chart.py루프의 검증자 · 대비표 형식 검사. 단독 실행과 Stop Hook 모두 가능받기
block_danger.py하네스의 Hook · 삭제·외부 전송 명령을 실행 전에 차단받기
settings.example.json위 두 Hook을 등록하는 Claude Code 설정 예시받기
state-example.json그래프 · 단계끼리 주고받는 공유 정보(상태)의 예시받기

권장 폴더 구성

내-분석-프로젝트/
├── CLAUDE.md
├── input/
│   ├── target/        대상 특허 (청구범위 + 상세한 설명)
│   ├── prior-art/     선행문헌
│   └── guidelines/    심사기준 발췌
├── output/            claim-chart.md 가 여기 만들어짐
└── .claude/           (고급) Hook 쓸 때만
    ├── settings.json  ← settings.example.json 이름 바꿔 넣기
    └── hooks/
        ├── block_danger.py
        └── check_claim_chart.py
확인 범위 — 두 Python 파일은 표준 라이브러리만 쓰며, Python 3.12에서 예시 파일로 실행해 PASS·FAIL·차단 동작을 확인했습니다. 검사기는 형식만 봅니다. 법적 판단이 맞는지는 사람이 검토해야 합니다.
