# 청구항 대비표 및 특허성 분석 (가상 예시)

> 이 문서는 형식을 보여 주기 위한 가상의 예시입니다. 실제 특허·문헌과 관계없습니다.

## 1. 분석 개요
- 발명의 명칭: 설비 상태 감시 장치
- 분석 대상 청구항: 제 1 항 (독립항)
- 비교 선행문헌: 선행문헌 1 (공개번호: KR 10-2024-0000000 A, 가상)
- 작성: IP 분석 에이전트 / 작성일: 2026-11-06 / 상태: 초안 (담당자 승인 전)

## 2. 구성요소별 대비표

| ID | 대상 청구항 구성요소 | 선행문헌 1 대응 기재 | 기술적 차이점·작용효과 |
|---|---|---|---|
| E1 | 설비 데이터를 수집하는 데이터 수집부 | 【0012】 개시 | 동일: 센서 데이터 수집 구성과 목적이 같음 |
| E2 | 수집된 신호를 필터링하는 신호 처리부 | 【0015】, 도 2 개시 | 차이: 선행문헌은 고정 필터, 대상 발명은 적응형 필터 |
| E3 | 이상 징후를 실시간 판단하는 모니터링 모듈 | 미개시 | 차이: 선행문헌은 일 단위 일괄 분석만 기재 (근거: 【0021】) |

## 3. 종합 분석

### 3.1 기술적 관점
- 구조·동작 원리 비교: E1은 실질적으로 같고, E2는 필터 방식이 다르며, E3에 대응하는 구성은 선행문헌에 없다.
- 작용효과: E3로 인해 이상 징후를 발생 즉시 감지할 수 있다 (명세서 【0040】 실험예: 감지 지연 약 30% 감소).

### 3.2 특허법적 관점
- 신규성 (특허법 제29조 제1항): 선행문헌 1에 E3가 개시되어 있지 않으므로 신규성은 부정되지 않는 것으로 보인다.
- 진보성 (특허법 제29조 제2항)
  - 구성의 곤란성: 선행문헌 1은 일괄 분석을 전제로 설계되어 있어 실시간 판단 구성으로 바꿀 동기가 드러나지 않는다 (【0021】).
  - 효과의 현저성: 감지 지연 감소 효과가 명세서 실험예로 뒷받침된다. 다만 다른 선행문헌과의 결합 가능성은 추가 검토가 필요하다.

## 4. 결론과 권리화 제안
- 분석 결과: 선행문헌 1만 놓고 보면 신규성·진보성 인정 여지가 있음. 추가 선행문헌 검색 필요.
- 권리화 제안: E3의 실시간 판단 구성을 독립항에 명확히 적고, 판단 알고리즘의 세부는 종속항으로 둔다.
