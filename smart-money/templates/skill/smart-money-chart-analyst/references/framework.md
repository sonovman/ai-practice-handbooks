# 분석 기준 — 다우 · 와이코프 · SMC

## 1. 일곱 가지 규칙

1. **주 추세를 따른다.** 주봉·일봉 스윙으로 방향을 정하고, 하위 시간대의 작은 흔들림은 잡음으로 본다. 역추세 계획은 세우지 않는다.
2. **꼬리보다 종가.** 꼬리로만 지지·저항을 넘었다가 돌아오면 유동성 스윕(속임수)일 수 있다. 구조 돌파·전환은 종가로 확정한다.
3. **상승(참여) 단계에서 적극적으로.** 축적 단계는 기다리고, 분배 단계는 가짜 돌파를 경계하고, 상승 단계에서 거래량 증가와 변위를 확인한 뒤 참여한다.
4. **추격하지 않고 되돌림을 기다린다.** 강한 파동 뒤 직전 파동의 약 33~66% 되돌림에서 OB·FVG 재방문을 기다린다.
5. **오더 블록의 세 조건.** ① 변위(몸통이 꽉 찬 큰 캔들) ② FVG(가격 공백) ③ 구조 돌파(BOS/MSS) — 셋 다 있을 때만 유효한 OB로 본다.
6. **노력 대 결과.** 돌파 때 거래량 증가 = 진짜 돌파 가능성 / 되돌림 때 수축 = 노 서플라이 / 고점 갱신인데 거래량 감소 = 다이버전스(힘이 빠짐).
7. **추세의 정의.** 상승 = 종가 기준 고점(HH)·저점(HL)이 계속 높아짐, 하락 = LH·LL. 직전 주요 스윙 저점이 종가로 깨지지 않으면 상승 추세가 유지된다.

## 2. 단계 — 다우의 3국면과 와이코프의 4단계

두 이론은 이름이 비슷해 섞이기 쉽습니다. 다우 이론은 큰 추세 하나를 **축적 → 대중 참여 → 과열(분배)**의 3국면으로, 와이코프는 가격 주기를 **축적 → 상승(markup) → 분배 → 하락(markdown)**의 4단계로 나눕니다. 이 스킬은 와이코프 4단계를 진단 이름으로 쓰고, 다우의 "대중 참여 국면"은 와이코프의 "상승 단계"에 대응시킵니다.

| 단계 | 알아보는 신호 | 기본 행동 |
|---|---|---|
| 축적 (Accumulation) | 긴 하락 뒤 좁은 횡보, 낮은 거래량, 하단 꼬리 이탈 후 빠른 회복(스프링), 큰 거래량에 작은 몸통(흡수) | 기다림. 상단 종가 돌파 + 거래량 증가 확인 |
| 상승 (Markup) | 박스 상단 돌파 + 거래량 증가, 변위 캔들, 얕은 조정에 거래량 수축, 깃발·삼각형 상방 돌파 | 되돌림에서 OB·FVG를 근거로 참여 |
| 분배 (Distribution) | 고점 갱신 + 거래량 감소, 전고점 살짝 돌파 후 급락(불 트랩), 큰 거래량 + 긴 위꼬리, 위아래 휩쏘 | 추격 금지, 보유분 분할 매도, 하락 전환 대비 |
| 하락 (Markdown) | 주요 스윙 저점 종가 이탈, 연쇄 손절, 반등 약함 | 매수 보류. 다음 지지에서 축적 신호를 기다림 |

## 3. 핵심 요소

| 요소 | 찾는 법 | 해석 |
|---|---|---|
| 꼬리 | 몸통 밖으로 나온 선 | 손절 물량을 체결시키는 유동성 사냥일 수 있음 |
| 종가 | 봉이 끝난 가격 | 구조 판단의 기준 |
| 변위 | 몸통 비율 큰 장대봉(평균 변동 폭의 1.3배 이상) | 큰 자금 투입 신호 |
| 오더 블록 | 변위 직전 마지막 반대색 캔들 | 되돌아왔을 때 지지·저항 후보 |
| FVG | 연속 3봉에서 1봉 고가와 3봉 저가 사이 공백(상승) | 가격이 되돌아와 메우려는 구간 |
| 유동성 풀 | 직전 스윙 고·저점 근처 | 손절 주문이 몰리는 목표 지점 |
| 흡수 | 큰 거래량 + 작은 몸통 | 반대 물량을 받아 내는 중 |
| 다이버전스 | 고점 갱신 + 거래량 감소 | 추세 피로 |
| 노 서플라이 | 조정 중 작은 봉 + 거래량 수축 | 매도 물량 고갈 |

## 4. 패턴 빠른 참조

| 패턴 | 단계 | 해석 |
|---|---|---|
| 깃발 | 상승 | 압축 후 추세 재개 |
| 직사각형 | 축적·분배 | 앞선 추세로 축적인지 분배인지 구분 |
| 상승 삼각형 | 상승 | 매수자가 매물을 흡수, 상방 돌파 후보 |
| 헤드 앤 숄더 | 분배→하락 | 넥라인 종가 이탈 시 하락 전환 |
| 쌍고점 / 쌍저점 | 분배 / 축적 | 같은 가격대 두 번 저항 / 지지 |
| 실패한 돌파 | 모든 단계 | 돌파 매수자 손절 뒤 반대 방향으로 크게 움직임 |

## 5. 한국 주식에서 더 볼 것

- **투자자별 매매동향**: 거래소가 종목별로 외국인·기관·개인의 순매수를 공개합니다(증권사 HTS의 종목별 투자자 화면, KRX 정보데이터시스템). 가격이 박스 하단에서 버티는 동안 외국인·기관 순매수가 이어지면 축적 해석을 뒷받침하고, 반대면 해석을 낮춥니다. 장중 수치는 잠정치이므로 확정치(장 마감 후)로 판단합니다.
- **갭**: 장 시작 갭이 잦아 일봉 FVG가 많이 생깁니다. 갭 FVG는 메워지지 않고 지나가는 경우도 많으니 다른 근거와 겹칠 때만 씁니다.
- **가격제한폭**: 상·하한가(±30%) 근처의 봉은 거래량·꼬리 해석이 평소와 다릅니다.
