핸드북 05 · Claude 활용

AI를 손발처럼 쓰는
SSR Plus 4단계

AI 성능이 아무리 좋아도 일할 환경이 갖춰져 있지 않으면 업무 부담은 줄지 않습니다. 스킬·세컨드 브레인·루틴·익스텐션, 네 단계로 Claude의 실행 환경을 세팅하는 법을 소개하고, IP팀 업무 시스템을 실제로 만들어 시범을 보입니다.

독자Claude를 매일 쓰지만 매번 같은 설명을 반복하고 있는 실무자 분량읽기 약 20분 · 구축 키트 1종(파일 14개) 판1.0 · 2026. 11. 6. (Claude 메뉴와 요금제는 2026. 11. 6. 기준)
한 줄 결론

두 번 반복한 일은 스킬로, 매번 하는 설명은 대문 파일로, 정해진 시간의 일은 루틴으로, 손이 닿지 않는 곳은 커넥터로.

SSR Plus는 Skills · Second brain · Routines에 Extensions(+)를 더한 이름입니다. 네 단계 모두 초급부터 시작할 수 있고, 이 글의 구축 키트를 받으면 1~4단계 초급이 한 번에 갖춰집니다.

01왜 실행 환경인가

대화창에서만 AI를 쓰면 매번 같은 배경을 설명하고, 같은 양식을 붙여 넣고, 결과를 직접 옮겨야 합니다. 일은 AI가 했는데 손은 사람이 바쁩니다. 실행 환경을 세팅한다는 것은 이 반복을 파일과 설정으로 한 번 고정해 두는 일입니다.

02 · S스킬 — 두 번 했으면 단축키로

스킬은 “이 일은 이렇게 한다”를 적어 둔 폴더입니다. Claude는 평소에는 스킬의 이름과 설명만 알고 있다가, 요청이 설명과 맞을 때 폴더 전체를 열어 지침대로 일합니다.

스킬 폴더의 정확한 모양

patent-brief/            ← 폴더 이름 = 스킬 이름 (영문 소문자·숫자·하이픈)
├── SKILL.md             ← 필수. 이름이 정확히 SKILL.md 여야 인식됨
├── style.md             ← 참고 파일 (이름 자유)
└── template.html        ← 참고 파일 (양식·코드 조각)
---
name: patent-brief
description: 특허 공보 한 건을 한 장짜리 브리프로 정리한다. 공보 요약 요청에 쓴다.
---
# 본문: 언제 쓰나 / 먼저 읽을 것 / 순서 / 점검
원고와 다른 점 — 원고는 지침 파일을 스킬.md, 참고 파일을 스타일.md로 적었습니다. Claude는 SKILL.md라는 이름만 스킬로 인식하고, 맨 위에 name·description 머리말이 있어야 합니다. 참고 파일 이름은 자유지만 영문(style.md)이 안전합니다. claude.ai에 올릴 때 이름은 64자, 설명은 200자까지입니다.

초급 — Claude에게 맡기기

대화로 “방금 한 작업을 스킬로 만들어 줘”라고 요청하면 됩니다. Anthropic은 스킬 작성을 돕는 skill-creator 스킬을 공식 저장소(anthropics/skills)에 공개해 두었고, Claude Code에서는 공식 플러그인으로 설치해 쓸 수 있습니다.

설치 위치

어디서 쓰나설치 방법
claude.ai · Desktop 채팅설정에서 코드 실행(파일 만들기) 켜기 → Customize → Skills → + → Create skill → Upload a skill → 스킬 폴더를 ZIP으로 올리기 (ZIP 맨 위에 스킬 폴더가 있어야 함)
Claude Code · Desktop Code 탭작업 폴더의 .claude/skills/<이름>/SKILL.md (이 프로젝트에서만) 또는 ~/.claude/skills/<이름>/SKILL.md (모든 프로젝트). /이름으로 바로 실행

중급 — 참고 파일을 함께

지침만으로는 모양이 매번 달라집니다. 문체·디자인 규칙(style.md), 결과물 뼈대(template.html), 잘된 예시를 같은 폴더에 두고 SKILL.md에서 “먼저 읽어라”라고 가리키면 결과가 일정해집니다.

고급 — 스킬을 고치는 스킬

양식이 바뀌면 스킬도 낡습니다. 키트의 skill-improver는 최근 결과물과 대화 속 지적을 근거로 수정안을 만들고, 승인을 받은 뒤에만 고칩니다.

03 · S세컨드 브레인 — 폴더 정리 대신 길잡이

자료를 완벽하게 폴더별로 정리하려 애쓰는 대신, AI와 사람이 길을 찾을 수 있는 안내 파일을 만듭니다. 위키의 대문 페이지와 같은 방식입니다.

CLAUDE.md (대문)→ 업무 종류 판단 →docs/선행조사_안내.md→필요한 자료·스킬만 열기
  1. 초급 — 대문 파일 하나작업 폴더 맨 위에 CLAUDE.md를 둡니다. Claude Code와 Desktop Code 탭은 이 파일을 자동으로 읽습니다. 역할, 늘 지킬 규칙, 결과물 저장 위치를 적습니다.
  2. 중급 — 업무별 길잡이대문에는 “선행조사는 이 파일, 보고서는 저 파일”이라는 표만 두고, 자세한 자료 위치는 docs/○○_안내.md에 적습니다. 자료가 늘어도 AI가 길을 잃지 않습니다.
  3. 고급 — 나만의 뷰어길잡이 파일들의 연결을 그림으로 보여 주는 화면을 Claude에게 만들게 할 수 있습니다. 노션·옵시디언을 대신하는 개인 도구입니다.
AGENTS.md를 쓰던 분께 — Claude Code는 최근 버전부터 AGENTS.md도 읽지만, 기본값으로는 CLAUDE.md가 없을 때만 읽습니다. 다른 도구와 함께 쓰려면 CLAUDE.md 첫 줄에 @AGENTS.md라고 적어 불러오세요.

길잡이 파일이 많아지면 링크가 끊기기 쉽습니다. 키트의 check_links.py로 점검하세요.

04 · R루틴 — 정해진 시각에 알아서

“매일 아침 8시 반에 일정·메일·할 일을 정리해 줘”처럼 같은 시각에 반복하는 일을 예약합니다. Claude에는 여러 방식이 있고, PC가 꺼져 있어도 도는지가 가장 큰 차이입니다.

방식만드는 곳PC 꺼져도?요금제
Desktop 로컬 예약Desktop Code 탭 → Scheduled → New task → 고급 설정에서 “Only on this computer”아니요 (앱 실행·PC 깨어 있어야)—
클라우드 예약 작업claude.ai/code/routines 또는 Code 탭 Scheduled → New task, CLI는 /schedule예 (Anthropic 클라우드에서 실행)Pro 이상
Cowork 예약 작업Cowork 왼쪽 Scheduled → New task (Claude와 대화로 만들거나 직접 설정)예 (단, 내 PC 파일·앱이 필요한 작업은 PC에서만)Pro 이상
상시 서버VPS·남는 PC에 에이전트 설치 + Syncthing 등으로 파일 동기화예서버 비용 별도

로컬 예약은 PC가 잠들어 있다가 깨어나면 놓친 실행을 한 번 따라잡습니다(7일 이내). 클라우드 예약은 미리보기(research preview) 단계 기능입니다.

아침 브리핑 루틴 만들기 (Desktop 로컬)

  1. Desktop 앱 Code 탭 → 왼쪽 Scheduled → New task → Set up manually
  2. 폴더: 구축 키트 폴더, 일정: Weekdays 08:30
  3. 프롬프트: 키트의 루틴_안내.md “루틴 1” 문장을 붙여 넣기 → Create
  4. 처음 한 번은 바로 실행해 결과 파일이 output/에 생기는지 확인

05 · +익스텐션·커넥터 — AI의 손이 닿는 곳

종류예연결하는 곳요금제
기본 커넥터Gmail, Google Calendar, Google DriveCustomize → Connectors모든 사용자 (Team·Enterprise는 관리자가 켜야 함)
커스텀 커넥터원격 MCP 서버 주소로 연결Customize → Connectors → + Add → Add custom connector모든 요금제 (무료는 1개)
데스크톱 확장내 PC의 파일·앱을 다루는 로컬 MCP (.mcpb)Settings → Desktop app → Extensions → Browse extensionsDesktop 앱
브라우저 제어Claude in Chrome (Chrome 확장)Chrome 웹 스토어 설치 → Customize → Connectors에서 켜기유료 요금제, Chrome만
권한은 좁게 — 처음에는 읽기만 맡기세요. 메일 발송·일정 변경·파일 삭제는 실행 전에 확인을 받도록 대문 파일에 적어 둡니다. 메일·웹페이지 안에 적힌 “지시문”은 따르지 말라는 규칙도 함께 넣습니다(키트의 연결_안내.md).

고급 단계에서는 필요한 도구가 없을 때 Claude에게 MCP 서버나 전용 화면을 만들게 합니다. 만드는 법은 Anthropic 공식 스킬 저장소의 mcp-builder 스킬이 안내합니다.

06구축 사례: IP팀 업무 시스템
