# 특허 브리프 스타일 (style.md)

patent-brief 스킬이 결과물을 만들 때 따르는 규칙입니다. 원하는 모양으로 바꿔 쓰세요.

## 1. 분위기
- 흑백 위주의 차분하고 단정한 보고서. 30초 안에 "무슨 특허이고, 우리와 관련 있는지"가 보여야 한다.

## 2. 문체
- "~함", "~임"으로 끝나는 짧은 개조식. 한 줄에 한 가지 사실.
- 원문 인용은 따옴표 없이 그대로 옮기고 끝에 【단락】을 단다.
- 추측 표현("~로 보임")은 관련성 이유에만 쓴다.

## 3. 디자인
- 글자색 #111, 보조 글자 #555, 선 #ddd, 배경 흰색.
- 강조는 굵게만. 색으로 강조하지 않는다.
- 관련성 배지만 예외: 높음 = 검정 바탕 흰 글자, 보통 = 테두리만, 낮음·판단 보류 = 회색 글자.

## 4. 구성 요소
- 맨 위: 발명의 명칭(제목) + 공보번호.
- 서지사항은 2열 표.
- 구성요소는 번호 목록(E1, E2 …).
- 맨 아래: "AI 작성 초안 · 담당자 검토 전" 문구를 반드시 남긴다.

## 5. 하지 말 것
- 원색 강조, 아이콘·이모지 남발.
- 템플릿에 없는 섹션 추가.
- 한 화면을 넘는 긴 문단.
