# 스킬 개선 스킬

## 언제 쓰나
- "patent-brief 스킬 점검해 줘", "이 스킬 요즘 결과가 이상해", "양식이 바뀌었어"

## 순서
1. 대상 스킬 폴더의 `SKILL.md` 와 참고 파일(style.md, template 등)을 모두 읽는다.
2. 개선 근거를 모은다. 아래 중 있는 것만 쓴다.
   - 이번 대화에서 사용자가 지적한 점
   - `output/` 에 있는 최근 결과물 3개 (스킬 규칙과 어긋난 곳 찾기)
   - 사용자가 준 새 양식이나 규정
3. 문제를 표로 정리한다: 문제 / 근거(파일·대화) / 고칠 곳 / 수정안.
4. 수정안을 사용자에게 보여 주고 승인을 기다린다. 승인 전에는 파일을 고치지 않는다.
5. 승인받은 것만 고치고, `SKILL.md` 맨 아래 "고친 기록"에 날짜와 한 줄 요약을 남긴다.

## 지킬 것
- 스킬의 목적을 바꾸지 않는다. 목적이 바뀌어야 하면 새 스킬을 제안한다.
- 머리말(name, description)을 고치면 description 은 200자 이내로 유지한다.
- 한 번에 고치는 항목은 5개 이내로 한다.
