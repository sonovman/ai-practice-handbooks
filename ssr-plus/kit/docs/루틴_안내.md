# 길잡이: 매일·매주 자동 업무 (루틴)

[← 대문으로](../CLAUDE.md)

예약 작업에 아래 문장을 그대로 붙여 넣으면 됩니다. 만드는 방법은 핸드북 05편 3단계를 보세요.

## 루틴 1. 아침 브리핑 (평일 08:30)
```
오늘 날짜 기준으로 다음을 확인해 한 화면 분량으로 정리해 줘.
1. 오늘 캘린더 일정 (시간·제목·참석자)
2. 어제 오후 이후 받은 메일 중 회신이 필요한 것 (보낸 사람·제목·한 줄 요지)
3. output/ 폴더에 어제 생긴 결과물 목록
맨 위에 "오늘 가장 먼저 할 일" 1개를 적어 줘.
메일 회신이나 일정 변경은 하지 말고 목록만 만들어 줘.
결과는 output/YYYY-MM-DD_아침브리핑.md 로 저장해 줘.
```
필요한 연결: Gmail, Google Calendar ([연결 안내](연결_안내.md))

## 루틴 2. 주간 공보 요약 정리 (금요일 17:00)
```
이번 주 output/ 에 생긴 patent-brief 결과물을 모두 읽고,
"우리 회사 관련성: 높음"인 건만 골라 표로 정리해 줘.
(공보번호 · 발명의 명칭 · 관련 제품군 · 다음 할 일)
결과는 output/YYYY-MM-DD_주간_공보정리.md 로 저장해 줘.
```
필요한 연결: 없음 (이 폴더만 사용)
