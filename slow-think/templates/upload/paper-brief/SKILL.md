# 논문 요약 — 근거 대조형

## 1. 준비
- 원문을 확인합니다. PDF면 텍스트를 뽑을 수 있는지 확인하고(스캔본이면 사용자에게 알림), 작업 폴더가 있으면 `work/papers/<짧은이름>/`에 요약을 저장합니다.
- **분야 판별**: 의학·생명 / AI·컴퓨터 / 사회과학·정책 / 기타 중 하나와 판별 근거 한 줄을 보여 주고, 애매하면 사용자에게 확인합니다.
- 독자를 묻습니다: 연구자 / 실무자 / 경영진. 답이 없으면 실무자.

## 2. 요약 구조
1. 메타 정보 — 제목, 저자, 연도·학술지, 분야와 판별 근거
2. **[원문] 공통 6항목** — 배경·문제 / 연구 질문·가설 / 방법(설계·데이터·표본 크기) / 주요 결과 / 기여(저자 주장) / 한계(저자가 밝힌 것)
3. **[원문] 분야별**
   - 의학·생명: PICO, 연구 설계(RCT·코호트·메타분석), 효과 크기와 신뢰구간, 임상시험 등록번호. 유의확률(p)만으로 '효과가 크다'고 쓰지 않습니다.
   - AI·컴퓨터: 문제 정의, 제안 방법의 핵심, 벤치마크·베이스라인과 개선 폭, 코드·데이터 공개, 연산 자원
   - 사회과학·정책: 이론 틀, 표본·수집 기간·방법, 측정 도구, 저자가 주장하는 정책 시사점
4. **[해석]** — 영향 범위, 기존 방법 대비 의미, 재현 가능성·신뢰도, 독자가 할 수 있는 다음 행동. 문장마다 기대는 가정을 괄호로.

## 3. 쓰는 규칙
- [원문] 문장마다 근거 구절을 “큰따옴표”로 원문 그대로, 가능하면 (p.쪽).
- 숫자·단위는 원문 그대로. 계산값은 `계산:`과 식.
- 원문에 없는 것은 '논문에 없음'.

## 4. 검증 (생략 금지)
1. 요약에서 틀리기 쉬운 주장 5개를 골라 원문에서 근거를 다시 찾고, 못 찾은 주장은 지웁니다.
2. 작업 폴더가 있으면 `python tools/evidence_check.py <원문> <요약.md> --report <폴더>/evidence.md`를 실행하고 실패 항목을 고칩니다.
3. 판정(통과·경고·실패)과 고친 내용을 요약 끝에 짧게 적습니다.
