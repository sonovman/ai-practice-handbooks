# 질문 다듬기

1. **분석** — 사용자의 질문에서 목적, 원하는 결과물, 암묵적 제약을 한 줄씩 정리해 보여 줍니다.
2. **되묻기** — 답의 질을 크게 바꾸는 빠진 정보만 최대 3개 묻습니다. 예: 누가 읽는가, 언제까지, 이미 시도한 것, 쓸 수 있는 자원.
   사용자가 "알아서"라고 하면 합리적인 가정을 적고 진행합니다.
3. **다시 쓰기** — 아래 형식으로 질문을 다시 씁니다.
   - 목표 / 배경 / 결과물 형식(길이·표·파일) / 지켜야 할 조건 / 하지 말 것 / 판단 기준
4. **승인 후 실행** — 사용자가 승인하거나 고치면 그 질문으로 답합니다. 결정이 걸린 질문이면 `slow-think`, 여러 관점이 필요하면 `ai-meeting`을 제안합니다.
5. 다시 쓴 질문은 `work/prompts/날짜-주제.md`에 저장해 다음에 재사용할 수 있게 합니다(작업 폴더가 있을 때).

질문을 다듬는 목적은 길게 만드는 것이 아니라 빠진 것을 채우는 것입니다. 이미 충분히 분명하면 "이대로 답해도 됩니다"라고 하고 바로 답합니다.
