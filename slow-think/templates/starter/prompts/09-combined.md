# 결합 프롬프트 — Slow Think를 회의·요약에 붙이기

## A. Slow Think + AI 회의 (한 대화 버전)

```
[Slow Think Execution Protocol]
Take a deep breath and work through this carefully. This is a complex decision that requires examining our assumptions.

0단계 — 전제 점검(공통): 안건 속 주장·숫자·인과를 | 전제 | 사실/가정/의심 | 근거 | 표로 정리하고, 모순 전제는 바로잡아 모든 참석자에게 공유해.
1단계 — 독립 의견: 콘텐츠 기획자·마케터·CFO·CEO가 다른 의견을 모른다고 가정하고 각자 씀.
  찬성 근거 최대 3 · 가장 강한 반대 논리 1 · 루브릭 점수(아래 정의)와 근거 한 줄 · 결론을 바꿀 정보 · 한 줄 결론
2단계 — 반론 전담: 1단계 의견들이 공통으로 기대는 결론·전제를 가장 강하게 반박. 동의하는 말은 쓰지 않음.
3단계 — 의장 종합(다수결 금지): 최종 합의안 / 보류 항목 표(항목 | 보류 사유 | 보류를 풀 조건) / 소수 의견 / 점수표(역할별 범위와 이견) / 확인할 사실

[루브릭] 1~10점, 정보 부족 시 '판단 보류'
실행 난이도(높을수록 쉬움) · 수익화(7↑ 계약·선주문 등 직접 신호) · 확장성(7↑ 고객이 늘어도 원가 거의 불변) · 리스크(높을수록 안전)

안건에 없는 사실은 지어내지 말고 '확인 필요'로 표시해.
[안건] <여기에>
```

## B. Slow Think + 논문 요약

```
[Slow Think Execution Protocol]
Take a deep breath and work through this carefully. Examine the paper's assumptions and the limits of its evidence before summarizing.

첨부한 논문을 요약해 줘.
1. 먼저 점검(표로): 연구 설계가 결론을 뒷받침하는가 / 표본·대조군·측정의 한계 / 저자가 주장하지만 데이터로 보이지 않은 것
2. [원문] 공통 6항목(배경·질문·방법·결과·기여·한계) — 문장마다 원문 구절을 “큰따옴표”로 그대로, 가능하면 (p.쪽)
3. [원문] 분야별 항목(의학: PICO·효과 크기·신뢰구간 / AI: 벤치마크·비교 대상·개선 폭·코드 공개 / 사회과학: 이론·표본·측정)
4. [해석] 의사결정 관점 — 문장마다 기대는 가정을 괄호로. 논문이 말하지 않은 효과·성능을 사실처럼 쓰지 않음
   분야별로 먼저 의심할 것 — 의학: 대리 지표를 실제 임상 결과처럼 쓰는가, 상대위험만 있고 절대위험은 없는가
   / AI: 비교 대상이 최신·동일 조건인가, 벤치마크가 학습 데이터에 섞였을 가능성 / 사회과학: 상관을 인과로 말하는가, 표본이 결론 범위를 대표하는가
5. 검증: 틀리기 쉬운 주장 5개를 골라 원문 근거를 다시 찾고, 못 찾은 주장은 지움
숫자·단위는 원문 그대로. 계산값은 '계산:'과 식. 모르는 것은 '논문에 없음'.
```

결과는 저장해서 `python tools/evidence_check.py 원문 결과.md`로 인용·수치를 대조하세요.
