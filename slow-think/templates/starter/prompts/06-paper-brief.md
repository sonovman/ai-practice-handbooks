# 논문 요약 마스터 프롬프트 (근거 대조형)

> 웹 앱에서 쓸 때는 논문 PDF를 첨부하고 아래를 붙여 넣습니다. 결과를 저장해
> `python tools/evidence_check.py 논문.pdf 요약.md`로 인용·수치를 대조하세요.

```
첨부한 논문을 요약해 줘. 규칙:
- 논문에 적힌 사실·수치·인용만 [원문] 구획에 쓴다. 문장마다 근거가 되는 원문 구절을 “큰따옴표”로 그대로 옮기고 (p.쪽)을 붙인다.
- 원문에 없는 해석·제언은 [해석] 구획에만 쓰고, 문장마다 어떤 가정에 기대는지 적는다.
- 숫자와 단위는 원문 그대로. 계산한 값은 '계산:'을 붙이고 식을 보인다.
- 모르는 것은 '논문에 없음'이라고 쓴다.

1. 메타 정보: 제목, 저자, 연도·학술지, 분야 판별(의학·생명 / AI·컴퓨터 / 사회과학·정책 / 기타)과 판별 근거 한 줄
2. [원문] 공통 6항목: 배경과 문제 / 연구 질문·가설 / 방법(설계·데이터·표본 크기) / 주요 결과 / 기여(저자가 주장하는 새로움) / 한계(저자가 밝힌 것)
3. [원문] 분야별 항목
   - 의학·생명: 대상(P)·개입(I)·비교(C)·결과(O), 연구 설계, 효과 크기와 신뢰구간, 임상시험 등록번호
   - AI·컴퓨터: 문제 정의, 제안 방법의 핵심, 벤치마크와 비교 대상(베이스라인), 개선 폭, 코드·데이터 공개, 연산 자원
   - 사회과학·정책: 이론 틀, 표본과 수집 기간·방법, 측정 도구, 정책 시사점(저자 주장)
4. [해석] 의사결정 관점: 영향 범위, 기존 방법 대비 의미, 재현 가능성과 신뢰도, 우리가 할 수 있는 다음 행동 — 각 문장에 가정 표시
5. 검증: 위 요약에서 틀리기 쉬운 주장 5개를 골라 각각 "원문 어디에 근거가 있는가"를 다시 찾아 적고, 찾지 못한 주장은 요약에서 지운다.
```
