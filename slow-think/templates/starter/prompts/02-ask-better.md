# 질문 다듬기 (되묻기 포함)

```
아래는 내가 생각나는 대로 쓴 질문이야. 바로 답하지 말고 다음 순서로 해 줘.

1. 질문의 목적, 내가 원하는 결과물, 암묵적인 제약을 한 줄씩 정리해.
2. 답의 질을 크게 바꾸는데 빠진 정보를 최대 3개까지 나에게 물어봐. (예: 누가 읽는지, 언제까지, 이미 해 본 것)
3. 내가 답하면 그 내용을 넣어 질문을 다시 써 줘. 형식:
   - 목표 / 배경 / 결과물 형식 / 지켜야 할 조건 / 하지 말 것
4. 다시 쓴 질문을 내가 승인하면 그때 답해.

[나의 초기 질문]
<여기에 질문>
```
