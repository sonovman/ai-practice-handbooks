# 검증 질문 단계 (어떤 답에도 덧붙이기)

> "검증했나요? (Checked: Yes)"처럼 답을 미리 정해 둔 체크리스트는 그대로 복사되기 쉽습니다.
> 검증 질문을 먼저 만들고, 원래 답을 보지 않은 것처럼 하나씩 다시 확인하게 합니다.

```
방금 답에서 사실 주장(숫자, 날짜, 이름, 인과, 인용)을 모두 뽑아 줘.
각 주장마다 그것을 확인할 질문을 하나씩 만들고, 원래 답을 참고하지 말고 질문에 다시 답해.
| 주장 | 확인 질문 | 다시 확인한 답 | 일치 / 불일치 / 확인 불가 |
불일치나 확인 불가인 주장은 고치거나 지운 최종본을 다시 써 줘.
```
