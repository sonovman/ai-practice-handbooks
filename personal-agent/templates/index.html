핸드북 04 · 자료

개인 에이전트 템플릿

파일 이름을 누르면 내용을 볼 수 있고, 오른쪽 버튼으로 내려받을 수 있습니다.

파일쓰는 곳
agent-instructions.mdClaude 프로젝트 · Copilot Studio · Gemini Gem의 지침 칸에 붙여 넣는 공용 지침받기
price-watch/SKILL.mdHermes Agent 스킬 · 바뀌었을 때만 알리는 감시 절차 (AI가 판단)받기
watch.py감시 스크립트 · Hermes 스크립트 예약 작업용, 또는 PC에서 단독 실행 (AI 호출 없음)받기

어디에 두나 (Hermes Agent)

~/.hermes/
├── skills/
│   └── price-watch/
│       └── SKILL.md      ← 폴더째 넣기
└── scripts/
    └── watch.py          ← 스크립트 예약 작업은 이 폴더 안의 파일만 실행

Windows에 Hermes를 직접 설치했다면 %LOCALAPPDATA%\hermes 아래에 같은 구조로 둡니다.

확인 범위 — watch.py는 Windows의 Python 3.12에서 실제 공개 환율 API로 8가지 경우를 시험했습니다(첫 실행, 변화 없음, 기준 미만 변동, 2% 변동, 정규식 모드, 주소 오류, 기록 파일 손상, 텔레그램 설정 누락). SKILL.md는 Hermes 공식 문서의 형식(name·description 머리말, When to Use·Procedure·Pitfalls·Verification)에 맞췄습니다. 두 파일 모두 Hermes 안에서 직접 돌려 보지는 않았으니, 처음 한 번은 hermes cron run <작업 이름>으로 바로 실행해 결과를 확인하세요.
