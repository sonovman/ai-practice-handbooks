핸드북 04 · 에이전트 활용

개인 AI 에이전트,
챗봇과 무엇이 다른가

“에이전트, 에이전트” 하는데 개인 AI 에이전트란 정확히 무엇일까요. ChatGPT·Claude 같은 챗봇과의 차이부터, 24시간 일하는 나만의 에이전트를 만드는 5단계 절차까지 정리했습니다. 명령어와 템플릿은 공식 문서와 실제 실행으로 확인했습니다.

독자코딩 경험 없이 에이전트를 처음 만들어 보려는 실무자 분량읽기 약 20분 · 따라 하기 30분~1시간 · 템플릿 3종 판1.0 · 2026. 11. 6. (서비스 화면과 정책은 2026. 11. 6. 기준)
한 줄 결론

챗봇은 내 다음 질문을 기다리고, 에이전트는 내가 자는 동안에도 맡긴 일을 한다.

차이는 모델의 똑똑함이 아니라 도구, 예약 실행, 기억, 알림 채널에 있습니다. 직접 서버에 띄우는 길(Hermes Agent)과 쓰던 서비스 안에서 만드는 길(Claude·Copilot·Gemini)이 있고, 처음이라면 둘 다 30분이면 첫 결과를 볼 수 있습니다.

01챗봇과 무엇이 다른가

챗봇은 질문하면 답하고 멈춥니다. 에이전트는 목표를 받으면 필요한 단계를 스스로 정하고, 도구를 써서 실행하고, 정해진 시간에 다시 일어나 같은 일을 반복합니다.

① 도구

직접 손을 쓴다

웹 검색, 파일 읽기·쓰기, 명령어·코드 실행을 스스로 합니다. 답을 “말해 주는” 데서 끝나지 않고 일을 “해 놓습니다”.

② 예약

시키지 않아도 일어난다

“6시간마다 확인해”처럼 일정을 걸어 두면, 내가 대화창을 열지 않아도 정해진 시각에 실행합니다(cron).

③ 기억·스킬

배운 것을 쌓는다

내 선호와 지난 결과를 기억하고, 한 번 해 본 절차를 스킬(단계별 작업 메모)로 저장해 다음에 다시 씁니다.

④ 채널

내가 있는 곳으로 온다

전용 웹사이트에 들어가지 않아도 텔레그램·슬랙·Teams 같은 메신저로 결과를 보내 줍니다.

목표→계획→도구로 실행→결과 확인→보고 · 기억→ (예약 시각에 반복)

02두 갈래 길: 직접 띄울까, 서비스 안에서 만들까

비교자체 서버 에이전트
예: Hermes Agent		플랫폼 에이전트
예: Claude 프로젝트, Copilot Studio, Gemini Gem
어디서 도나내가 빌린 서버(VPS)나 내 PC서비스 회사의 클라우드
모델여러 회사 모델 중 골라 바꿈 (Nous Portal 기준 300개 이상)대체로 그 서비스가 정한 모델
예약 실행내장 cron. 서버가 켜져 있는 한 계속서비스마다 다름. Claude는 유료 요금제에서 예약 작업 지원, Copilot은 Power Automate 흐름으로
할 수 있는 일서버 안에서 명령어·파일·스크립트까지서비스가 열어 준 도구와 연결 앱 범위
알림텔레그램·디스코드·슬랙·왓츠앱·시그널 등해당 앱, Copilot은 Teams 등
관리설치·보안·업데이트를 내가 챙김회사가 관리. 사내 보안 정책을 적용하기 쉬움
비용서버 월 고정비 + 모델 사용료(쓴 만큼)요금제 구독료
원고·영상과 달라진 점 — 자체 서버 에이전트라도 “사용량 제한이 없다”는 뜻은 아닙니다. 모델 사용료와 모델 회사의 한도는 그대로 적용됩니다. 또 이제는 플랫폼 쪽에도 예약 실행(Claude 예약 작업 등)이 생겨, 둘의 차이는 “가능·불가능”보다 통제 범위와 관리 부담의 차이에 가깝습니다.

03구축 5단계: Hermes Agent로 24시간 에이전트 만들기

영상에서 쓴 방식입니다. 명령어는 2026. 11. 6. 기준 Hermes 공식 문서와 대조했습니다.

  1. 에이전트 고르기 — Hermes Agent Nous Research가 만든 무료 오픈소스(MIT) 에이전트입니다. 스킬 자동 생성, 기억, 예약 실행, 메신저 연동이 기본으로 들어 있습니다.
  2. 일할 곳 정하기 — 24시간 켜진 서버(VPS) PC가 꺼져도 돌아야 하므로 월 몇 달러짜리 가상 서버를 빌립니다. 영상은 호스팅 업체의 원클릭 템플릿을 썼지만, 어느 리눅스 서버든 아래 한 줄로 설치됩니다. 개인 문서·금융 정보가 있는 PC와 떨어져 있다는 것도 장점입니다. 
    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
source ~/.bashrc
    먼저 맛만 보려면 Windows PC에도 설치할 수 있습니다(PowerShell: iex (irm https://hermes-agent.nousresearch.com/install.ps1)). 다만 PC를 끄면 예약 작업도 멈춥니다.
  3. 두뇌 연결 — 모델 고르기 
    hermes setup --portal    # Nous Portal 로그인 + 모델 + 검색 등 도구를 한 번에
hermes model             # 다른 회사 모델로 바꾸고 싶을 때
    Nous Portal 하나로 300개 이상의 모델과 웹 검색 같은 도구를 함께 쓸 수 있고, OpenRouter·OpenAI 등 원하는 회사의 키를 직접 넣어도 됩니다. 영상은 감시 업무에 값싼 DeepSeek 계열 모델을 골랐습니다. 단순 반복 업무에는 싼 모델로 충분합니다.
  4. 메신저 연결 — 텔레그램
    1. 텔레그램에서 @BotFather에게 /newbot을 보내고, 이름과 bot으로 끝나는 아이디를 정하면 봇 토큰을 줍니다.
    2. @userinfobot에게 말을 걸어 내 숫자 사용자 ID를 확인합니다.
    3. 서버에서 hermes gateway setup → Telegram을 고르고 토큰과 내 ID를 넣습니다. (대시보드의 “Create with QR”로도 할 수 있습니다.)
    4. hermes gateway install로 서비스 등록을 하면 서버가 재시작돼도 계속 돕니다.
    5. 봇과의 대화창에서 /sethome을 보내 이 대화를 홈 채널로 정합니다. 예약 작업 결과가 여기로 옵니다.
  5. 첫 임무 맡기기 — 바뀌면 알려 줘 텔레그램에서 이렇게 말하면 됩니다. 
    원-달러 환율을 6시간마다 확인해서, 0.5% 넘게 바뀌었을 때만 알려 줘.
    직접 명령으로 걸 수도 있습니다. 다음 장의 price-watch 스킬을 붙이면 판단 기준이 일정해집니다. 
    /cron add "every 6h" "원-달러 환율 감시. 기준 0.5%" --skill price-watch
/cron list               # 등록된 작업 보기
hermes cron run <작업>   # 기다리지 않고 지금 한 번 실행
“바뀌었을 때만” 알리는 원리 — Hermes는 예약 작업의 최종 답이 정확히 [SILENT]이면 메시지를 보내지 않습니다. 그래서 스킬에 “변화가 없으면 [SILENT]로 끝내라”고 적어 둡니다.

04실습: 바뀌었을 때만 알려 주는 감시자

같은 일을 두 방식으로 만들 수 있습니다. 판단이 필요한 대상은 A, 값이 정해진 곳에 있는 대상은 B가 좋습니다.

A · AI가 판단

스킬 price-watch

에이전트가 웹을 찾아보고 지난 기록과 비교해 판단합니다. 페이지 구조가 바뀌어도 대처하지만, 실행할 때마다 모델 사용료가 듭니다.

SKILL.md 보기

B · 스크립트

watch.py

정해진 주소에서 값을 읽어 비교만 합니다. AI를 부르지 않아 모델 비용이 0이고 결과가 항상 같습니다. 대상 페이지 구조가 바뀌면 설정을 고쳐야 합니다.

watch.py 보기

A. 스킬 방식

  1. price-watch 폴더를 서버의 ~/.hermes/skills/ 안에 넣습니다.
  2. 텔레그램에서 /price-watch 원-달러 환율, 기준 0.5%로 한 번 시험합니다. 첫 실행은 “감시를 시작합니다”가 나와야 정상입니다.
  3. 3장의 /cron add … --skill price-watch로 예약합니다.

B. 스크립트 방식

  1. watch.py 맨 위 [설정]에서 이름·주소·값 위치·알림 기준을 정합니다. 기본값은 키 없이 쓰는 공개 환율 API입니다.
  2. 서버의 ~/.hermes/scripts/에 넣고 예약합니다. 
    hermes cron create "every 6h" --no-agent --script watch.py --deliver telegram --name fx-watch
  3. 스크립트가 글자를 출력하면 그대로 텔레그램으로 가고, 아무것도 출력하지 않으면 조용히 넘어갑니다. 확인에 실패하면(오류 종료) Hermes가 오류 알림을 보냅니다.

Hermes 없이 PC에서도 돌릴 수 있습니다. python watch.py로 확인하고, 환경변수 TELEGRAM_BOT_TOKEN·TELEGRAM_CHAT_ID를 넣은 뒤 python watch.py --telegram을 Windows 작업 스케줄러에 걸면 됩니다.

실제로 시험한 결과

상황출력결과
첫 실행[원-달러 환율] 감시를 시작합니다. 현재 값: 1347.69…알림 1회
값 그대로(출력 없음)알림 없음
0.1% 변동(출력 없음)기준 0.5% 미만 → 알림 없음
2% 변동[원-달러 환율] ▲ 1,320.74 → 1,347.69 (+2.04%)알림
주소 오류확인 실패: HTTP Error 404오류 종료 → 오류 알림
기록 파일 손상감시를 다시 시작멈추지 않고 복구

2026. 11. 6. Windows의 Python 3.12로 실행. 2% 변동은 기록 파일의 이전 값을 바꿔 재현했습니다. Hermes 서버 안에서의 실행은 독자 환경에서 hermes cron run으로 확인하세요.

IP 업무에 쓰려면 — 같은 구조로 경쟁사 보도자료 페이지, 공개 공보 목록 페이지의 변동을 감시할 수 있습니다. watch.py의 REGEX에 감시할 부분을 지정하거나, 스킬 방식으로 “새 항목이 생기면 제목과 링크만 알려 줘”라고 맡기면 됩니다. 사이트 이용약관이 자동 수집을 막는지 먼저 확인하고, 공식 API가 있으면 그쪽을 쓰세요.

05플랫폼 에이전트 만들기

서버를 다루기 부담스럽다면 이미 쓰는 서비스 안에서 시작하세요. 지침은 공용 지침 템플릿 하나를 붙여 넣으면 됩니다.

Claude — 프로젝트

  1. 왼쪽 Projects → + New Project → 이름과 설명 입력
  2. Set project instructions에 지침 붙여 넣기 → Save
  3. 오른쪽 프로젝트 지식 영역의 +로 참고 문서 올리기
  4. 정기 실행이 필요하면 유료 요금제의 예약 작업: 대화에서 할 일과 주기를 말하고 Schedule (PC가 꺼져 있어도 원격으로 실행)

프로젝트는 무료 계정도 쓸 수 있으며(최대 5개), 예약 작업은 유료 요금제에서 제공됩니다.

Microsoft — Copilot Studio

  1. copilotstudio.microsoft.com 홈에서 만들고 싶은 에이전트를 설명 → 이름·설명·지침이 자동 생성
  2. Overview에서 Instructions를 공용 지침으로 다듬기
  3. Knowledge에 사내 사이트·문서 연결
  4. Tools → Add a tool에서 Agent flow(Power Automate)를 붙여 메일 발송·승인 같은 작업 연결
  5. Publish → Channels에서 Microsoft 365 and Microsoft Teams를 골라 배포

회사 라이선스와 관리자 설정에 따라 메뉴와 가능한 기능이 다릅니다. 체험판 에이전트는 게시할 수 없습니다.

Google — Gemini Gem

  1. gemini.google.com 왼쪽 Gems 탐색하기 → 새 Gem
  2. 이름을 정하고 요청 사항에 지침 붙여 넣기 (“Gemini를 사용해 요청 사항 다시 작성하기”로 다듬을 수도 있음)
  3. 파일 업로드나 Drive로 참고 자료 추가
  4. 오른쪽 미리보기로 시험한 뒤 반드시 저장 (미리보기는 자동 저장되지 않음)

ChatGPT — 맞춤형 GPT는 종료 예정

OpenAI는 맞춤형 GPT를 2026. 12. 11.에 종료하고 플러그인(지침은 스킬로, 지식 파일은 참조 파일로)으로 옮기는 중입니다. 개인 계정(Free·Go·Plus·Pro)에서는 이미 새 GPT를 만들 수 없습니다. 원고에 있던 “Explore GPTs → Create” 절차는 기존 GPT를 고치거나 플러그인으로 옮길 때만 해당합니다.

지식 파일을 잘 올리는 법 (공통)

  • 제목 구조를 분명히: 문서 안에 큰 제목·작은 제목을 나눠 두면 필요한 부분을 정확히 찾습니다.
  • 용어집을 앞에: 사내 약어와 전문 용어 정의를 문서 첫머리에 둡니다.
  • 표는 단순하게: 셀 병합이 많은 표는 잘못 읽히기 쉽습니다. 표 아래 글로 요약을 덧붙이세요.
  • 파일 이름에 주제와 연도: 문서1.pdf보다 2026_선행조사_가이드.pdf
  • 글 위주 파일(.md, .txt, 글로 된 PDF)이 가장 잘 읽힙니다.

06비용과 안전

비용

  • 서버: 소형 VPS 월 몇 달러 수준(업체·사양에 따라 다름)
  • 모델: 쓴 만큼. 감시처럼 짧은 작업은 값싼 모델로 1회 몇 원 이하인 경우가 많습니다. 스크립트 방식(B)은 모델 비용이 들지 않습니다.
  • 영상 설명란의 할인 링크는 제휴 링크라고 영상에 밝혀져 있습니다. 이 글은 공식 사이트만 안내합니다.

안전 체크리스트 (Hermes 공식 보안 문서 기준)

항목할 일
누가 말을 걸 수 있나TELEGRAM_ALLOWED_USERS에 내 숫자 ID만. 모르는 사람은 기본으로 거부됨. GATEWAY_ALLOW_ALL_USERS=true는 쓰지 않기
위험 명령승인 모드 기본값(smart) 유지. 위험한 명령은 실행 전에 확인을 받음
격리개인 PC보다 별도 서버. 더 엄격히 하려면 hermes config set terminal.backend docker
